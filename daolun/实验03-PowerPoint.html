📖 关键术语速览

演示文稿一个 .pptx 文件即一个演示文稿，由多张幻灯片组成。
幻灯片 / 版式单页内容；版式是占位符的预设布局（标题、内容、节标题…）。
母版统一控制所有幻灯片字体、背景、占位符的"模板"。
动画 / 切换动画控制同一张幻灯片内对象出现方式；切换控制幻灯片之间的过渡。
节(Section)把演示文稿分成可命名、可整体移动的分组。
放映方式演讲者放映（全屏）、观众自行浏览、展台浏览等模式。

📁① 演示文稿创建与保存

学习目标：掌握新建、打开、保存、另存为，以及导出为 PDF 或视频。

📌 操作步骤

打开 PowerPoint，选择 新建 → 空白演示文稿。
输入第一张幻灯片标题"产品介绍"，副标题"市场部"。
文件 → 保存，命名为"产品介绍.pptx"。
文件 → 另存为 → PowerPoint 放映 (.ppx)，双击即可直接进入放映。
文件 → 导出 → 创建 PDF/XPS，便于分发与打印。
文件 → 导出 → 创建视频 (MP4)，把整份演示文稿录制成视频。
文件 → 信息 → 保护演示文稿，选择"始终以只读方式打开"或"用密码加密"。

🔑 必须掌握

新建 / 保存 / 另存为
PDF 导出
MP4 视频导出
文件信息与作者
只读 / 密码保护
最近使用的文件
练习：新建"自我介绍.pptx"，写一张封面幻灯片，保存为 PPTX 和 PDF 各一份。
小贴士：把做好的模板另存为 PowerPoint 模板 (.potx)，下次直接基于此模板新建，可保持公司统一风格。

🗂️② 幻灯片编辑与版式

这一部分训练"幻灯片管理能力"——新增、复制、移动、删除幻灯片与节。

📌 操作步骤

左侧缩略图区，右键 → 新建幻灯片，或快捷 Ctrl+M。
选中幻灯片 → 右键 → 版式，选择合适的占位符布局。
Ctrl + 拖动复制；Alt + 上下箭头快速调整顺序。
Ctrl + 鼠标拖动到其他节，可整片移动。
缩略图区右键 → 新增节，给节命名"产品介绍""价格""结束"。

📌 视图选择

视图适合场景
普通视图日常编辑（默认）
大纲视图只看标题文字，快速改结构
幻灯片浏览整体看效果、调整顺序
备注页视图给每页加演讲备注
阅读模式全屏翻页预览
小贴士：建立"节"是管理长演示文稿的关键。汇报类演示可分为"开场 / 主体 / 结尾"三节，便于整体移动与放映分组。
练习：制作一份 10 页的"读书分享"演示文稿，按"封面 / 目录 / 三章正文 / 总结"建立节。

🔤③ 文本与段落格式

PPT 中的文字比 Word 更"视觉化"：字号要大、行距要宽、关键信息要突出。

📌 字体与字号

标题字号建议 ≥ 36 号，正文字号 ≥ 24 号，确保投影清楚。
字体优先选择简洁的无衬线体，如微软雅黑、思源黑体。
避免在同页使用超过 3 种字体。

📌 段落格式

行距建议 1.2–1.5 倍，段前段后留 6–12 磅空白。
项目符号和编号：使用"开始 → 项目符号"自定义样式，避免默认大点。
艺术字：标题可用，慎用——只在重点处使用。
常见错误：把大段文字直接粘贴到 PPT。规则：一页不超过 6 行字，每行不超过 12 字。多字不如换图。
实战对比：
❌ "今天我们讨论人工智能的发展历史、关键技术、主要应用、未来趋势、伦理问题、政策建议。"（一行字）
✅ 拆成 5 张幻灯片，每页一个要点 + 大图。

🧩④ 插入对象

📌 图片与形状

插入 → 图片 → 此设备，选择本地图片。
右键图片 → 设置图片格式：裁剪、颜色、效果、版式。
插入 → 形状，选择矩形/箭头/流程图/动作按钮。
组合：选中多个对象 → 格式 → 组合。

📌 SmartArt

类型 → 用途对照：
层次结构：组织架构
流程：业务流程
循环：持续改进
关系：中心辐射
列表：并列要点
操作：开始 → 转换为 SmartArt，把项目列表直接变图形。

📌 图表与表格

插入 → 图表：柱形图、折线图、饼图等。编辑数据用配套 Excel 窗口。
插入 → 表格：适合简单数据展示，复杂数据建议用图表。

📌 音频与视频

插入 → 音频 → 此设备，选 mp3/wav；插入后图标显示在幻灯片上。
音频工具 → 播放：跨幻灯片播放、循环播放、设为背景。
插入 → 视频 → 此设备 / 联机视频。
小贴士：演示文稿中的大图应当压缩到 200 KB 以内，否则文件会很大。可以用 文件 → 压缩图片。

🎨⑤ 主题与母版

用主题+母版统一整套演示文稿的外观——这是"专业感"的来源。

📌 主题

设计 → 主题：选择内置主题（柏哥斯、离子、柏林等）。
变体：每种主题有 4 种颜色、3 种字体组合。
设计 → 自定义 → 颜色 / 字体 / 效果：创建自己的主题颜色。

📌 幻灯片母版

视图 → 幻灯片母版，进入母版视图。
顶部是主母版，下方是若干版式。
编辑母版：在背景层添加 LOGO、页脚占位符、统一背景。
关闭母版视图返回普通视图。
对单张幻灯片：设计 → 背景 可单独覆盖。
常见错误：每张幻灯片单独设置背景/字体——这是大忌，会让整体风格零散。一定要用母版。
练习：自定义一个"绿色商务"主题色，然后在母版中加入公司 LOGO、一致的页脚文字。

✨⑥ 动画与切换效果

📌 动画类型

类型作用典型用法
进入对象如何出现浮入、淡出、擦除、缩放
强调对象出现后再变化脉冲、陀螺旋、加粗闪烁
退出对象如何消失淡出、飞出
动作路径沿自定义路径移动直线、弧线、自定义

📌 使用步骤

选中对象 → 动画 → 添加动画，挑选类型。
动画窗格查看顺序与计时。
开始 → 单击时 / 与上一动画同时 / 上一动画之后。
持续时间 / 延迟 / 重复 设置节奏。

📌 切换效果

选中一张幻灯片 → 切换选项卡。
选择切换效果（推入、淡出、擦除、分割…）。
设置声音（建议关闭自动声音）和持续时间（建议 0.8 秒以内）。
勾选全部应用统一所有幻灯片切换。
常见错误：每张幻灯片用不同的花哨切换 — 视觉混乱。建议同主题演示用 1 种切换即可。
小贴士：动画越多越慢 — NCRE 二级考试要求"恰到好处"。能用切换表达，就不要用动画。
练习：为 3 张幻灯片分别设置：浮入进入 + 推入切换；强调脉冲 + 淡出切换；自定义路径 + 分割切换，并调整计时。

🔗⑦ 超链接与动作按钮

📌 超链接

选中对象（文字、图片、形状）→ 插入 → 链接 → 超链接。
类型：本文档中的位置（跳到指定幻灯片）/ 网页 / 文件 / 电子邮件。
勾选屏幕提示，鼠标悬停时显示提示文字。

📌 动作按钮

插入 → 形状 → 动作按钮，选"第一张""上一张""下一张""最后一张"等。
在页面绘制按钮 → 自动弹出"动作设置"对话框。
选超链接到：幻灯片 / URL。

📌 自定义放映

幻灯片放映 → 自定义放映 → 新建。
输入名称（例如"汇报摘要"），挑选若干张幻灯片加入。
放映时选择该自定义放映，只播放被选中的幻灯片。
小贴士：同一份演示文稿可以创建多个自定义放映（如"完整版""精简版"），按场合调用。
练习：制作一个"公司介绍"演示，目录页 3 个文字按钮分别跳到第 3、5、7 页，并在每页右下角放置"返回第一张"的动作按钮。

▶️⑧ 放映与导出

📌 放映方式

方式用途
演讲者放映（全屏）演讲者控制进度，看到备注
观众自行浏览（窗口）对方可自主翻阅
展台浏览（全屏）无人值守循环播放

📌 演讲者模式

放映时右键 → 勾选演讲者视图。
主屏幕显示幻灯片，副屏显示备注、计时、下一张缩略图。

📌 排练计时

幻灯片放映 → 排练计时。
边讲边记录，结束后提示是否保存新的幻灯片时间。
启用"使用排练计时"后，放映时按预设时间自动翻页。

📌 导出

文件 → 导出 → 创建 PDF/XPS：保留排版，便于打印分发。
文件 → 导出 → 创建视频 (MP4/WMV)：把整套演示文稿录制成视频。
导出选项可选择是否包含旁白、计时、幻灯片大小。
小贴士：导出的 PDF 可设置页眉/页脚包含幻灯片编号，方便讨论时定位。MP4 视频可加上录制旁白，作为远程汇报资料。

🎯综合实训：制作《产品发布演示文稿》

完成 8 个模块后，用一个完整项目检验是否真正掌握 PowerPoint。

📌 项目要求

建议页数：12–16 页
结构：封面 → 公司简介 → 产品概述 → 核心卖点（SmartArt）→ 数据图表 → 用户案例 → 价格方案 → 竞品对比 → 总结 → 谢谢观看
目标读者：潜在客户与合作伙伴

封面 + 目录页

🪜 推荐完成步骤

选 1 种主题，进入母版统一字体、背景、页脚。
封面 + 目录页 + 节标题 + 内容页，建立 4 个节。
在"核心卖点"页插入 SmartArt "层次结构"，放入 3 个子项。
在"数据图表"页插入柱形图 + 折线图的组合图。
在"价格方案"页插入表格 + 动作按钮"点击咨询"。
为所有幻灯片添加 1 种切换效果；在"核心卖点"页为 SmartArt 添加"淡出"动画。
为目录页的章节标题添加超链接到对应节首页。
排练计时记录每页时长，导出 PDF 与 MP4 各一份。
