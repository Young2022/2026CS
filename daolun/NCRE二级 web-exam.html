HTTP 协议

理论 · 高频考点

大纲要求：HTTP 基本概念与交互模型、消息格式、请求消息与常用请求方法、响应消息与常用响应状态、常用消息头。

HTTP 请求消息结构

HTTPGET /index.html HTTP/1.1      ← 请求行
Host: www.example.com          ← 请求头
Connection: keep-alive
                              ← 空行
                              ← 请求正文（GET 通常为空）

GET 与 POST 对比（必考）

GETPOST
获取资源提交数据
参数拼在 URL 中，可见数据放在请求体，不直接显示在 URL
常用于查询常用于表单提交
有长度限制数据量通常更大

HTTP 状态码（必须重点掌握）

状态码含义状态码含义
200OK，请求成功400Bad Request
201Created，创建成功401Unauthorized
301永久重定向403Forbidden
302临时重定向404Not Found
304Not Modified500Internal Server Error
速记：2xx 成功 ｜ 3xx 重定向 ｜ 4xx 客户端错误 ｜ 5xx 服务器错误。 HTTP/1.1 的持久连接（keep-alive）默认打开。

CSS

操作题核心 · ★★★★★

大纲要求：基本概念、基本语法、使用方法、选择器、层次及优先级、布局设计。是必须重点掌握的操作部分。

三种使用方式与优先级

CSS/* 1. 行内样式 */
<p style="color:red;">

/* 2. 内部样式（head 中） */
<style> p { color: red; } </style>

/* 3. 外部样式 */
<link rel="stylesheet" href="style.css">
优先级：行内样式 > 内部（文档）样式 > 外部样式；选择器之间：ID 选择器 > 类选择器 > 标签选择器，可用 !important 提升优先级。

选择器（非常重要的考点）

选择器写法含义
标签选择器p { color:red; }所有 p 元素
类选择器.title { color:blue; }class="title" 的元素
ID 选择器#header { height:80px; }id="header" 的唯一元素
后代选择器div p { }div 内部所有 p
子元素选择器div > p { }div 的直接子级 p

常用属性速查

  • 字体：font-family / font-size / font-weight / font-style
  • 文本：color / text-align / text-decoration / line-height / letter-spacing
  • 背景：background / background-color / background-image
  • 尺寸：width / height
  • 边框：border / border-radius
  • 间距：margin（外边距）/ padding（内边距）

DOM 文档对象模型

重点中的重点 · ★★★★★

DOM（Document Object Model）把网页表示为树形结构，JavaScript 通过 DOM 操作网页元素。控制文档结构的是 DOM，不是 CSS。

document
└─ html
head
body → div / p / input / button …

获取元素（必须熟练）

JSdocument.getElementById("box")          // 按 id，返回单个元素
document.getElementsByTagName("p")     // 按标签，返回集合
document.getElementsByClassName("item") // 按类名，返回集合
document.querySelector("#box")         // CSS 选择器，第一个
document.querySelectorAll(".item")     // CSS 选择器，全部

修改内容与样式

JS// 修改 HTML 内容
document.getElementById("text").innerHTML = "Hello World";
document.getElementById("text").textContent = "Hello World";

// 修改 CSS（注意驼峰命名）
let box = document.getElementById("box");
box.style.width = "200px";
box.style.backgroundColor = "yellow";

↓ 返回数据

2022单项选择题真题精选
下列协议中，用于在 Web 浏览器和服务器之间传输 Web 文档的是？
答案 C。HTTP（超文本传输协议）负责浏览器与 Web 服务器之间的文档传输；FTP 是文件传输，DNS 负责域名解析。
2022单项选择题真题精选
下列语言编写的代码中，在浏览器端执行的是？
答案 D。JavaScript 是客户端脚本，在浏览器中执行；C#（ASP.NET）、PHP、JSP/Servlet 都在服务器端执行。
2022单项选择题真题精选
下列技术中，控制文档结构的是？
答案 A。DOM（文档对象模型）定义文档的结构；CSS 控制外观样式，JavaScript 是操作 DOM 的语言。
2023单项选择题真题精选
HTTP 协议是一种什么协议？
答案 D。HTTP = HyperText Transfer Protocol，超文本传输协议。
2023单项选择题真题精选
在 HTTP/1.1 协议中，持久连接（keep-alive）选项是？
答案 B。HTTP/1.1 默认启用持久连接，同一连接可传输多个请求/响应，减少连接建立开销。
2023单项选择题真题精选
以下哪一项不是 HTTP 协议的特点？
答案 C。HTTP 响应的 MIME 消息体可同时包含文本、图片、视频、音频等多种类型数据。
2024单项选择题题库精选
下列函数中，能够把 6.25 四舍五入为最接近整数的是？
答案 D。JavaScript 数学函数必须通过 Math 对象调用，且没有 rnd 方法；Math.round() 四舍五入，Math.floor() 向下取整，Math.ceil() 向上取整。
2024单项选择题题库精选
HTTP 请求消息中可以不包含的是？（① 请求行　② 消息头　③ 消息体实体数据）
答案 C。请求行是必须的；GET 请求通常没有消息体，部分简单请求也可以不带消息头。
2024单项选择题题库精选
关于浏览器对象之间的从属关系，正确的说法是？
答案 B。window 是 BOM 的顶层对象，document 是 window 的属性（DOM 的入口），所以 alert() 可省略 window 前缀。
2024单项选择题题库精选
下列哪个不是 JSP 的内置对象？
答案 C。JSP 九大内置对象包括 request、response、session、out、application 等；cookie 不是内置对象。
2025单项选择题教育考试院官方样题
下列关于域名系统 DNS 的描述中，正确的是？
答案 B。DNS（域名系统）是分布式数据库，负责把便于记忆的域名解析为 IP 地址；传输网页是 HTTP 的职责。

2026单项选择题模拟预测 · 依据 2025 版大纲
浏览器请求一个并不存在的页面时，服务器返回的状态码通常是？
答案 C。404 Not Found 表示资源不存在；500 是服务器内部错误，301/302 是重定向。
2026单项选择题模拟预测 · 依据 2025 版大纲
执行 5 === "5" 的结果是？
答案 B。=== 严格相等，同时比较类型和值：Number 与 String 类型不同，结果为 false；若用 == 则为 true。
2026单项选择题模拟预测 · 依据 2025 版大纲
关于 GET 与 POST 方法，下列说法错误的是？
答案 C。POST 数据在请求体中，不受 URL 长度限制；受 URL 长度限制的是 GET。
2026单项选择题模拟预测 · 公共基础
数据结构中的"栈"具有什么特点？
答案 B。栈是后进先出（LIFO）；先进先出（FIFO）是队列的特点。公共基础知识占选择题 10 分。
