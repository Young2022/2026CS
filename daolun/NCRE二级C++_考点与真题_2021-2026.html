基本控制结构

操作题核心 · ★★★★★

大纲要求：C++ 基本语句；顺序、选择（if / switch）、循环（for / while / do-while）结构；break、continue、return 跳转语句；选择与循环的嵌套。

三种循环对比

循环判断时机最少执行次数典型场景
while(条件)先判断0 次条件循环
do{...}while(条件)后判断1 次至少执行一次
for(初始化;条件;更新)先判断0 次计数循环；for(;;) 为无限循环

switch 的 break 穿透

C++switch (b) {
    case 1:  cout << "A"; break;
    case 2:  cout << "B";     // 无 break：继续往下执行
    case 3:  cout << "C"; break;
    default: cout << "D";
}
// b=2 → 输出 BC（穿透到 case 3 的 break 才停）

break / continue / return

  • break：跳出当前层循环或 switch；嵌套中只跳一层
  • continue：跳过本次循环剩余语句，进入下一轮
  • return：结束整个函数并返回；在 main 中结束程序

官方样题：do-while 追踪

C++int x = 3;
do {
    x -= 2;
    cout << x;
} while (!(--x));
// 第 1 轮：x=1，输出 1；--x 后 x=0，!0=1 真 → 继续
// 第 2 轮：x=-2，输出 -2；--x 后 x=-3，!(-3)=0 假 → 结束
// 输出：1-2 → 官方样题 03 选 C
官方样题 04：int k=1,num=26; do{k*=num%10; num/=10;} while(num); 运行后 k 的值 → B）12。追踪：第 1 轮 k=6、num=2；第 2 轮 k=12、num=0 结束。

引用

大纲要求：类与对象的概念、数据成员/成员函数与访问控制；构造函数与析构函数（初始化列表、默认构造、复制构造）；this 指针；静态成员；常对象与常成员函数；友元；成员对象；对象数组与自由存储对象。

类定义与访问控制

C++class Point {
private:              // 默认访问权限：private
    int xx, yy;
public:
    Point() : xx(0), yy(0) {}        // 构造函数（初始化列表）
    Point(int x, int y = 0) : xx(x), yy(y) {}  // 重载 + 默认参数
    int getX() const { return xx; }  // 常成员函数
};
Point a(2), b[3];    // 对象、对象数组：a 调 1 次构造，b 调 3 次

构造函数与析构函数

构造函数析构函数
名称与类同名，可重载~类名，不能重载，一个类仅一个
参数/返回可有参数，无返回类型无参数、无返回值
时机对象创建时自动调用对象生命周期结束时自动调用
特殊形态默认构造、复制构造（参数为本类引用）可声明为 virtual（虚析构）
  • 复制构造函数在对象按值传给函数、按值返回对象、用对象初始化另一对象时被调用
  • 编译器仅在类没有定义任何构造函数时才自动生成默认构造函数
  • 静态数据成员：必须在类外单独定义和初始化（int Test::b = 0;），所有对象共享一份
  • 静态成员函数：只能访问静态成员；没有 this 指针

this 指针 / 常对象 / 友元

C++class Test {
private:
    int a;
public:
    void set(int v) { this->a = v; }   // this 指向当前对象（非静态成员函数都有）
    int get() const { return a; }       // const 成员函数：不能修改数据成员
    friend void show(const Test &t);  // 友元函数：可访问私有成员，无 this 指针
};
const Test t;   // 常对象：只能调用常成员函数（const 成员函数）

官方样题 15：关于 this 指针 → D）类的非静态成员函数都有 this 指针。 静态成员函数与友元函数没有 this 指针。

构造与析构顺序（高频）

C++class A{ public: A(){cout<<"A";} ~A(){cout<<"~A";} };
class B : public A {
    A *p;
public: B(){cout<<"B"; p = new A();}
          ~B(){cout<<"~B"; delete p;}
};
B obj;
// 构造：基类 A → 派生类 B 体 → 成员（p=new A）  输出：ABA
// 析构：~B（delete p 触发 ~A）→ 基类 ~A           输出：~B~A~A
// 合计：ABA~B~A~A → 官方样题 23 选 B

虚函数与多态

C++class Base {
public:
    void fun1(){ cout << "Base\n"; }                       // 非虚
    virtual void fun2(){ cout << "Base\n"; }            // 虚函数
};
class Derived : public Base {
public:
    void fun1(){ cout << "Derived\n"; }                   // 隐藏
    void fun2(){ cout << "Derived\n"; }                   // 覆盖（重写）
};
void f(Base &b) { b.fun1(); b.fun2(); }
Derived obj;  f(obj);
// fun1 非虚：编译期绑定 → Base；fun2 虚：运行期按实际对象 → Derived
// 输出：Base / Derived → 官方样题 26 选 B
  • 纯虚函数：virtual void f() = 0;；含纯虚函数的类是抽象类，不能实例化对象
  • 虚函数：不能是静态成员函数（官方样题 16 选 B）；通过基类指针/引用调用实现运行时多态
  • 虚析构函数：基类析构声明为 virtual，保证通过基类指针 delete 派生类对象时正确调用派生析构
  • 多重继承：构造顺序按基类声明顺序（不是初始化列表顺序）；同名成员产生二义性时用虚基类 virtual 解决
官方样题 17：关于基类和派生类关系 → D）派生类除了继承基类的成员，还可以定义新的成员。 （A 错：C++ 支持多继承；B 错：私有成员不可访问；C 错：基类构造在初始化列表调用而非构造体。）

运算符重载

选择+简单应用 · ★★★★

大纲要求：运算符重载的概念与注意事项；典型运算符的重载方式；作为成员函数与非成员函数（友元）重载的两种形态。

重载规则与限制

  • 只能重载 C++ 中已有的运算符，不能定义新运算符（官方样题 07 选 C）
  • 不能改变运算符的优先级和操作数个数
  • 不能重载的运算符：.（成员访问）、::（域解析）、.*、?:（三目）、sizeof
  • 不能重载为友元函数的：=（赋值）、()（函数调用）、[]（下标）、->（成员访问）——只能作为成员函数（官方样题 09 选 A）

成员函数 vs 友元函数重载

C++// 双目运算符：成员函数重载时，左操作数由 this 提供，显式参数只需 1 个
class Complex {
public:
    Complex operator+(const Complex &c) const;   // 成员：1 个参数
    friend Complex operator-(const Complex &a, const Complex &b);
};                                                 // 友元：2 个参数

// 前缀 ++ 与后缀 ++：后缀多一个 int 哑元（仅用于区分）
Complex &operator++();            // 前缀 ++a
Complex operator++(int);         // 后缀 a++

流提取 >> / 流插入 << 重载

C++class MyClass {
private:
    int data;
public:
    friend istream& operator>>(istream& is, MyClass& a) {
        is >> a.data;   // 友元：才能访问私有 data
        return is;
    }
};
// 要点：第一参数是 istream&（返回引用才能连续 >>）；第二参数必须是"引用"才能改对象
// 官方样题 12 选 A：friend istream& operator>>(istream& is, MyClass& a);

解决方案 proj3 定义了表示矩阵的类 Matrix，operator+ 的功能是实现两个矩阵的加法运算（对应元素相加）。请编写 operator+ 函数：补充的内容写在 //*******333******* 与 //*******666******* 两行之间，不得修改程序的其他部分（结果已由 writeToFile 输出到 out.dat）。
参考答案（完整函数） 
C++Matrix operator+(const Matrix &m1, const Matrix &m2) {
    Matrix c(m1.rows, m1.cols);      // 与 m1 同尺寸的结果矩阵
    for (int i = 0; i < m1.rows; i++)
        for (int j = 0; j < m1.cols; j++)
            c.data[i][j] = m1.data[i][j] + m2.data[i][j];
                                            // 对应元素相加
    return c;
}
// 要点：返回新矩阵（值返回）；先构造结果对象再逐元素相加；
// 成员名（rows/cols/data）以题给类定义为准，不能自己改名
