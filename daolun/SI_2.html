计算机基础：数制、编码、布尔代数与位掩码

Number Systems · Data Representation · Character Encoding · Boolean Algebra · Bit Masks

从数字表示到逻辑运算与位操作，理解计算机如何表示、存储和处理信息

学习目标 Learning Objectives

本讲讨论计算机中非常基础的问题：信息如何用二进制表示？计算机如何通过逻辑运算和位操作处理信息？

完成本讲后，你应该能够：

  • 理解二进制、八进制、十进制和十六进制的表示方法。
  • 熟练进行不同进制之间的转换。
  • 理解原码、反码和补码的基本概念。
  • 区分 ASCII、Unicode 和 UTF-8。
  • 掌握布尔代数的基本运算和常用定律。
  • 利用布尔代数定律化简逻辑表达式。
  • 理解位掩码的概念，并能使用掩码进行置位、清零、检测和翻转操作。
核心思想：计算机内部使用二进制表示数据，逻辑电路通过布尔运算实现数据处理，位掩码则利用按位逻辑运算高效地选择和操作特定比特位。

01 数制基础 Number Systems

1. 什么是数制？

数制（Number System）是表示数值的一套规则。不同数制的主要区别在于使用的数字符号以及进位规则。

数制英文名称基数使用的数字
二进制Binary20、1
八进制Octal80–7
十进制Decimal100–9
十六进制Hexadecimal160–9、A–F

2. 位权（Positional Weight）

在位置计数法中，一个数字的实际数值取决于它所在的位置。每一位的权值是基数的相应次方。

(1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = (11)₁₀

同理：

(325)₈ = 3×8² + 2×8¹ + 5×8⁰ = (213)₁₀
(2A)₁₆ = 2×16¹ + 10×16⁰ = (42)₁₀

3. 为什么计算机使用二进制？

计算机硬件主要由数字电路构成。数字电路容易区分两种稳定状态，例如：

逻辑状态典型电压示意二进制表示
低电平（Low）接近 0 V0
高电平（High）接近某个规定的高电压1

说明：实际电压范围取决于具体芯片的逻辑电平标准，并非所有计算机都使用相同电压。

二进制的优点包括：电路实现相对简单、抗干扰能力较好、便于实现逻辑运算。

02 进制转换 Number Conversion

1. 任意进制转换为十进制

方法：每一位数字乘以对应位权，然后将结果相加。

例题：将 (110101)₂ 转换为十进制。
1×2⁵ + 1×2⁴ + 0×2³ + 1×2² + 0×2¹ + 1×2⁰
32 + 16 + 4 + 1 = (53)₁₀

2. 十进制整数转换为二进制

方法：不断除以 2，记录每次的余数，最后从下向上读取余数。

例题：将 (25)₁₀ 转换为二进制。
计算商余数
25 ÷ 2121
12 ÷ 260
6 ÷ 230
3 ÷ 211
1 ÷ 201
(25)₁₀ = (11001)₂

3. 二进制与八进制、十六进制转换

二进制转八进制：从右向左，每 3 位分成一组。

110 101 011₂ = 6 5 3₈ = (653)₈

二进制转十六进制：从右向左，每 4 位分成一组。

0010 1101 1010₂ = 2 D A₁₆ = (2DA)₁₆
记忆方法：八进制对应 3 个二进制位，十六进制对应 4 个二进制位。

03 整数表示与补码 Signed Integers

1. 为什么需要有符号数？

计算机不仅需要表示正数，还需要表示负数。常见的有符号数表示方法包括原码、反码和补码。

2. 原码 Sign-Magnitude

最高位作为符号位：0 表示正数，1 表示负数；其余位表示数值大小。

十进制数8 位原码
+500000101
-510000101

3. 反码 One's Complement

正数的反码与原码相同；负数的反码是其正数原码按位取反（符号位也取反）。

+5：00000101　　-5：11111010

4. 补码 Two's Complement

正数的补码与原码相同。负数的补码可以通过以下步骤获得：

  1. 写出对应正数的二进制表示。
  2. 对每一位进行取反，得到反码。
  3. 在反码基础上加 1，得到补码。
例题：求 -5 的 8 位补码。

+5 的二进制：00000101

取反：11111010

加 1：11111011

(-5) 的 8 位补码 = 11111011

5. 8 位补码的表示范围

-2⁷ ≤ x ≤ 2⁷ - 1，即 -128 ≤ x ≤ 127
注意：8 位补码中，10000000 表示 -128，而不是 -0。补码只有一个 0。

04 常用编码 Character Codes

1. 什么是编码？

编码（Encoding）是为字符、数字或其他信息分配特定二进制表示的规则。计算机通过编码将人类可读的信息转换为可以存储和处理的数据。

  • 可以表示 128 个字符。
  • 包括英文字母、数字、标点符号和控制字符。

05 Unicode 与 UTF-8

1. 为什么需要 Unicode？

ASCII 主要满足英文字符的编码需求，但世界上存在大量语言和文字。不同地区曾经使用不同字符编码，容易造成文本显示错误。

Unicode（统一码）为世界上绝大多数现代文字系统中的字符分配统一的码点（Code Point）。

2. Unicode 与 UTF-8 有什么区别？

Unicode：定义字符对应的码点，例如字母 A 对应 U+0041。

UTF-8：一种将 Unicode 码点编码为字节序列的方式。

UTF-16：另一种 Unicode 编码方式，使用一个或两个 16 位代码单元表示一个码点。

3. UTF-8 的编码长度

Unicode 码点范围UTF-8 字节数
U+0000 – U+007F1 字节
U+0080 – U+07FF2 字节
U+0800 – U+FFFF3 字节
U+10000 – U+10FFFF4 字节

4. 字符编码观察器

输入英文、中文或其他字符，观察其 Unicode 码点与 UTF-8 字节。

UTF-8 对 ASCII 字符保持兼容。因此，字母 A 在 ASCII 和 UTF-8 中都使用一个字节 0x41。

06 布尔代数 Boolean Algebra

1. 什么是布尔代数？

布尔代数（Boolean Algebra）是一种研究逻辑变量和逻辑运算的数学系统。逻辑变量只有两种取值：

0 = False（假）　　1 = True（真）

2. 三种基本逻辑运算

运算符号含义

逻辑或 ORA + B至少一个输入为 1，输出就为 1
逻辑非 NOTĀ 或 ¬A将输入取反

07 布尔代数公理与常用定律

布尔代数定律是逻辑表达式化简的基础。以下使用 + 表示 OR，· 表示 AND，横线或 ¬ 表示 NOT。

定律逻辑与表达式逻辑或表达式
恒等律 IdentityA·1 = AA+0 = A
支配律 DominationA·0 = 0A+1 = 1
幂等律 IdempotentA·A = AA+A = A
互补律 ComplementA·Ā = 0A+Ā = 1
双重否定 Involution¬(¬A) = A
交换律 CommutativeA·B = B·AA+B = B+A
结合律 Associative(AB)C = A(BC)(A+B)+C = A+(B+C)
分配律 DistributiveA(B+C) = AB+AC；A+BC = (A+B)(A+C)
吸收律 AbsorptionA+AB = A；A(A+B) = A

德摩根定律 De Morgan's Laws

¬(A·B) = ¬A + ¬B
¬(A+B) = ¬A · ¬B

含义：一个整体的 AND 取反，等于各变量分别取反后进行 OR；一个整体的 OR 取反，等于各变量分别取反后进行 AND。

记忆方法：整体取反时，AND 和 OR 互换，括号内每个变量也要取反。

08 布尔表达式化简 Simplification

1. 为什么要化简逻辑表达式？

复杂的逻辑表达式通常需要更多逻辑门电路。化简表达式可以减少逻辑门数量、降低电路复杂度，并有助于降低功耗和延迟。

2. 例题一：利用吸收律

化简：Y = A + AB
  1. 原式：Y = A + AB
  2. 提取公因子：Y = A(1+B)
  3. 利用支配律：1+B = 1
  4. 最终结果：Y = A

3. 例题二：利用分配律与互补律

化简：Y = AB + A B̄
  1. 原式：Y = AB + A B̄
  2. 提取公因子 A：Y = A(B+B̄)
  3. 利用互补律：B+B̄ = 1
  4. 利用恒等律：A·1 = A
  5. 最终结果：Y = A

4. 例题三：利用德摩根定律

化简：Y = ¬(A+B) + A
  1. 使用德摩根定律：Y = Ā·B̄ + A
  2. 利用分配律：Y = (A+Ā)(A+B̄)
  3. 利用互补律：A+Ā = 1
  4. 利用恒等律：Y = 1·(A+B̄)
  5. 最终结果：Y = A+B̄

5. 例题四：较复杂的化简

化简：Y = AB + ĀB + AB̄
  1. 合并前两项：Y = B(A+Ā) + AB̄
  2. 利用互补律：Y = B + AB̄
  3. 利用分配律：Y = (B+A)(B+B̄)
  4. 利用互补律：Y = (A+B)·1
  5. 最终结果：Y = A+B

6. 化简的基本策略

  • 寻找可以提取的公因子。
  • 寻找互补项，如 A+Ā 或 AĀ。
  • 使用吸收律消除多余项。
  • 使用德摩根定律处理复杂的取反表达式。
  • 通过真值表验证化简前后的表达式是否等价。

09 位掩码 Bit Masks

位掩码（Bitmask / Mask）是计算机中利用二进制位进行高效状态管理与数据筛选的核心技术，与布尔代数中的按位运算紧密相关。

1. 什么是掩码？

掩码是一串二进制数字，通过与目标数据的按位操作（AND、OR、XOR、NOT），可以有选择地保留、清除、设置或翻转某些比特位，从而达到“屏蔽”或“提取”指定位的目的。

形象理解：掩码就像一把“遮罩”，把你不关心的位遮住（变成 0），只留下需要关注的位。

2. 掩码与布尔代数的关系

位掩码的操作本质上就是布尔代数中按位与、或、非、异或运算的实际应用：

操作运算符掩码作用布尔代数对应
按位与 AND&清零指定位 / 检测位A · B
按位或 OR|置位（设为 1）A + B
按位异或 XOR^翻转指定位A ⊕ B
按位取反 NOT~生成掩码的补码形式¬A

3. 四种核心操作

（1）置位（Set Bit）—— 使用 OR

想把某几位置为 1，其他位保持不变，就用“或”运算。

结果 = 原数 | 掩码

例：把 8 位数 0100 1010 的第 0 位和第 3 位置 1：

0100 1010 | 0000 1001 = 0100 1011

（2）清零（Clear Bit）—— 使用 AND + NOT

想把某几位清为 0，其他位保持不变，就用“与”运算配合掩码的取反。

结果 = 原数 & (~掩码)

例：把 0100 1010 的第 1 位和第 3 位清零（掩码 = 0000 1010）：

0100 1010 & 1111 0101 = 0100 0000

（3）检测（Test / Check Bit）—— 使用 AND

判断某一位是否为 1：

若 (原数 & 掩码) ≠ 0，则该位为 1

例：判断 0100 1010 的第 3 位是否为 1（掩码 = 0000 1000）：

0100 1010 & 0000 1000 = 0000 1000 ≠ 0 → 是 1

（4）翻转（Toggle Bit）—— 使用 XOR

把指定位取反，其他位不变：

结果 = 原数 ^ 掩码

例：翻转 0100 1010 的第 1 位和第 4 位：

0100 1010 ^ 0001 0010 = 0101 1000

4. 生成掩码的常用技巧

  • 1 << n：生成第 n 位为 1 的掩码（从右往左，从 0 开始计数）
  • (1 << k) - 1：生成低 k 位全为 1 的掩码
  • 多个位掩码可用 OR 合并：mask = (1<<2) | (1<<5)

5. 经典应用示例

例题 1：权限管理（状态标志）

用一个整数的低 4 位分别表示读、写、执行、删除权限：

权限掩码二进制
读 READ1 << 00001
写 WRITE1 << 10010
执行 EXECUTE1 << 20100
删除 DELETE1 << 31000

用户权限 = READ | WRITE = 0011（十进制 3）

检查是否有写权限：(权限 & WRITE) != 0 → 真

增加删除权限：权限 = 权限 | DELETE → 1011

取消写权限：权限 = 权限 & ~WRITE → 1001

例题 2：提取低 4 位（屏蔽高位）

原数 1101 0110，只想保留低 4 位：

掩码 = 0000 1111
1101 0110 & 0000 1111 = 0000 0110
例题 3：子网掩码（网络中的应用）

IP 地址与子网掩码做按位与运算，可得到网络地址。例如：

IP：192.168.1.100 → 11000000.10101000.00000001.01100100

掩码：255.255.255.0 → 11111111.11111111.11111111.00000000

网络地址 = IP & 掩码 = 192.168.1.0

这是掩码在计算机网络中的典型应用，本质上仍是位掩码的 AND 操作。

6. 常见考试 / 考点提示

  • 能根据题目要求写出正确的掩码（如“清除第 2、5 位”应使用什么掩码）。
  • 熟练掌握四种基本操作对应的运算符。
  • 理解 1 << n 的含义及位编号从右向左从 0 开始。
  • 能解释为什么用 & ~mask 清零而不是直接用某个数。
  • 在权限、状态寄存器、标志位、位域等场景中识别掩码的使用。
注意：在有符号整数中使用 ~ 取反时要小心符号扩展问题；实际编程中常使用无符号类型或明确位数。
