📖 关键术语速览

文档 / 模板新建空白文档或基于模板（.dotx）；默认扩展名为 .docx。
字体 / 段落字体格式控制"字"（字号、字形、颜色）；段落格式控制"一段文字"（缩进、行距、段间距）。
样式一组预设的格式组合（如"标题1""正文"），是自动目录和长文档结构的基础。
分页符 / 分节符分页符只是换页；分节符还能让不同节拥有不同页面方向、页眉、页码格式。
题注 / 交叉引用题注给图、表编号；交叉引用可重复引用同一编号，编号自动更新。
修订 / 批注修订记录对原文的增删改；批注是给作者的备注，不修改正文。

📁① 文档的创建和保存

学习目标：掌握新建、打开、保存、另存为以及 PDF 导出。

📌 操作步骤

打开 Word，选择 新建 → 空白文档。
输入标题和基本信息，例如"计算机科学导论第一章"。
选择 文件 → 保存，设置保存位置、文件名和文件类型。
使用 文件 → 另存为 创建"计算机科学导论第一章-修改版.docx"。
使用 文件 → 导出 → 创建PDF/XPS，生成PDF版本。

🔑 必须掌握

新建 / 打开
保存 / 另存为
PDF / XPS 导出
设置文档属性（标题、作者）
模板新建（.dotx）
文件加密与权限

⌨️ 必备快捷键

Ctrl+N 新建空白文档 Ctrl+S 保存 Ctrl+Shift+S 另存为 Ctrl+O 打开 Ctrl+P 打印 Ctrl+F12 另存为 PDF
练习：创建"我的第一份Word文档.docx"，输入姓名、专业、学号和日期；保存后关闭，再打开修改内容，最后另存为 PDF。
小贴士：在公司做模板时，把字体、页眉、页脚、样式都预设好，另存为 .dotx，团队成员基于模板新建即可保持统一格式。

⌨️② 文本的输入、编辑与格式化

这一部分训练最基本的文字处理能力：输入、选择、删除、复制、剪切、粘贴、查找、替换以及字体格式设置。

📌 操作步骤

输入："Microsoft Word 是一款常用的文字处理软件。"
用鼠标选择"Microsoft Word"，在 开始 → 字体 中设置字体、字号。
使用 B 加粗、斜体、下划线和字体颜色等功能。
按 Ctrl+F 查找"Word"。
按 Ctrl+H，将"Word"替换为"Microsoft Word"。
尝试格式刷：先选已设置好格式的文字，单击格式刷，再刷另一段。

⌨️ 必备快捷键

Ctrl+C 复制 Ctrl+X 剪切 Ctrl+V 粘贴 Ctrl+Z 撤销 Ctrl+A 全选 Ctrl+F 查找 Ctrl+H 替换 Ctrl+B/I/U 加粗/斜体/下划线
常见错误：直接粘贴网页内容会带格式。正确做法：右键 → 仅粘贴文本，或粘贴后按 Ctrl+Shift+N 清除格式。
练习：输入一段约 200 字的"计算机科学简介"，分别练习复制、移动、删除、查找、替换，并对标题和关键词设置不同字体格式。

🧱③ 段落格式设置与样式应用

核心理念：字符格式处理"字"，段落格式处理"一段文字"，样式则用于建立整个文档的结构。

📌 段落格式

必须掌握：左对齐、居中、右对齐、两端对齐、首行缩进、左右缩进、行距、段前/段后间距、项目符号和编号。

选择正文，使用 开始 → 段落 → 两端对齐，也可按 Ctrl+J。
打开段落设置，将"特殊格式"设为首行缩进 2 字符。
设置行距，例如 1.5 倍，并设置段后间距，例如 8 磅。
对列表使用项目符号或编号，不要用空格模拟列表。

📌 样式应用

示例结构：
"第一章 计算机基础" → 标题1
"1.1 计算机的发展" → 标题2
"1.1.1 早期计算机" → 标题3
正文段落 → 正文
重要：不要靠手动修改字号来制作标题。正确使用"标题1、标题2、正文"等样式，是自动目录、导航窗格和长文档排版的基础。
练习：对"计算机科学导论"作业，应用样式构建三级标题结构，在导航窗格中观察文档结构。

📄④ 页面设置与排版技巧

📌 页面设置

打开 布局 → 页面设置。
设置纸张为 A4，方向通常为纵向。
根据课程或单位要求设置上下左右页边距，例如上/下 2.5 cm、左 3 cm、右 2.5 cm。
设置装订线（用于装订成册的文档）。

📌 分页、分栏与分节

换页：不要连续按 Enter 换页，应使用 Ctrl+Enter 或 插入 → 分页。
分栏：新闻稿等页面可使用 布局 → 分栏 → 两栏。
分节：当不同部分需要不同页眉、页码或页面方向时使用分节符。

⚠️ 初学者常见错误

连续敲空格来对齐
连续按 Enter 来换页
手动制作目录
逐个标题手动设置格式
用空格制作表格
大量下划线制作空白区域
正确方法：使用制表位、段落设置、样式、分页符、分节符和表格等 Word 功能。
练习：把一份 3 页文档在第 2 页后插入分节符，让前两页页码为罗马数字，第 3 页开始为阿拉伯数字并从 1 开始。

🧩⑤ 插入表格、图片、图表等对象

📌 5.1 表格

例如制作学生成绩表：

姓名数学英语计算机
张三859092
李四788886
王五928595

操作：插入 → 表格 → 选择行列；然后练习插入/删除行列、合并/拆分单元格、调整行高列宽、边框、底纹和对齐。

📌 5.2 图片

选择 插入 → 图片 → 此设备，插入一张 CPU 结构示意图。
调整图片大小（拖动角点，按 Shift 等比缩放）。
在 图片格式 → 文字环绕 中练习嵌入型、四周型、紧密型、上下型等。
使用 引用 → 插入题注 添加"图1-1 CPU基本结构"等题注。
常见问题：图片"拖不动"通常与图片的文字环绕方式有关；初学者要重点理解"嵌入型"和"四周型"等环绕方式的区别。

📌 5.3 图表

选择 插入 → 图表，练习柱形图、折线图和饼图。例如将"张三85、李四78、王五92"的成绩制作成柱形图。

📌 5.4 文本框与形状

在排版时常用文本框做"图文穿插"或加注释；插入形状则用于流程图、标注等。两者都可以设置文字环绕。

📚⑥ 目录生成、页眉页脚设置

📌 6.1 自动目录

将"第一章 计算机基础"设置为标题1。
将"1.1 计算机的发展""1.2 计算机的组成"等设置为标题2。
将光标放到文档开头，选择 引用 → 目录 → 自动目录。
修改正文后，右键目录 → 更新域 → 更新整个目录。
自动目录效果：
第一章 计算机基础 ………… 1
　1.1 计算机的发展 ………… 2
　1.2 计算机的组成 ………… 4
第二章 计算机硬件 ………… 8

📌 6.2 页眉、页脚和页码

选择 插入 → 页眉，例如设置"计算机科学导论"。
选择 插入 → 页码，添加页面编号。
进一步练习：首页不同、奇偶页不同、从指定页面开始编号。
核心关系：标题样式 → 文档结构 → 自动目录。掌握这一链条后，长文档处理会明显容易。
常见错误：目录页想从第 1 页开始，而封面页也想计页 — 解决方法是封面/目录与正文用分节符分开，并在第二节"页码格式"中重新从 1 开始编号。

📨⑦ 邮件合并功能

核心思想：一个 Word 模板 + 一组数据 → 自动生成大量个性化文档。

📌 案例：批量生成学生成绩通知书

姓名专业成绩
张三计算机科学92
李四软件工程88
王五人工智能95
Word 模板：
尊敬后的{{姓名}}同学：
您所在专业为{{专业}}。成绩为{{成绩}}分。
特此通知。
准备 Excel 数据表，第一行设置字段名：姓名、专业、成绩。
打开 Word 模板，选择 邮件 → 开始邮件合并 → 信函。
选择 选择收件人 → 使用现有列表，连接 Excel 文件。
在模板对应位置插入"姓名""专业""成绩"等合并字段。
选择 完成并合并，生成个性化文档。
小贴士：需要进一步控制称呼（先生/女士）？在 Word 中按 Ctrl+F9 插入 { IF { MERGEFIELD 性别 } = "男" "先生" "女士" } 域。
练习：建立 10 名学生的 Excel 数据，一次生成 10 份学生成绩通知书。

🔍⑧ 文档审阅与修订功能

主要应用于老师批改作业、论文修改、同事协作和项目文档版本管理。

📌 8.1 修订

选择 审阅 → 修订，开启修订功能。
修改句子，例如将"Word 是一款文字处理软件"修改为"Microsoft Word 是一款常用的文字处理软件"。
Word 会记录增加和删除的内容。
使用 审阅 → 接受 或 审阅 → 拒绝 处理修改。

📌 8.2 批注

选择文字 → 审阅 → 新建批注。例如："这里需要增加参考文献。"修改完成后可解决批注。

📌 8.3 比较两个版本

例如已有"论文V1.docx"和"论文V2.docx"，选择 审阅 → 比较 → 比较两个版本，Word 可以帮助识别增加、删除和修改内容。
核心区别：修订是对原文的改动（要记字）；批注是给作者的备注（不记字）。考试常考区分两者。
练习：和同学交换一篇文档，分别开启修订模式进行修改，体验接受/拒绝/批注的操作。
