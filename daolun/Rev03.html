01

图灵机：读、写、移动

计算模型 · 纸带 · 读写头 · 状态转移

知识要点

  • 图灵机由 无限长纸带、读写头、有限状态控制器、转移函数 组成。
  • 形式化：M = (Q, Σ, Γ, δ, q0, q_accept, q_reject)；Γ 包含空白符 □，Σ ⊆ Γ \ {□}。
  • 一步转移：δ(q, a) = (q', b, D)，含义是“读当前格 a → 写 b → 左移/右移 → 进入 q'”。
  • 读把当前格符号送入控制器，不改变纸带；写用 b 覆盖当前格。
  • 标准模型一步只访问一格；读、写、移动、变状态是一个原子动作，不能一步读写多格。
  • 纸带无界，图灵机可能不停机；停机问题不可判定。
图灵机简单计算机
纸带主存储器
读写头MAR / MDR + 读写控制
有限状态控制器PC + 控制单元 / 状态寄存器
转移函数指令系统 / 微程序
停机HALT 指令

注意：这是概念类比。图灵机逐格移动，主存可随机访问；图灵机纸带无界，真实内存有限。

例题 1｜把连续的 1 改成 0

设计图灵机：纸带上连续的 1 全部改成 0，遇到空白停机。

状态读入写入移动次态
q010Rq0
q0□□NqH

输入 111□ 的执行过程：

步骤状态纸带读写头动作
0q0111□第 1 格读到 1
1q0011□第 2 格写 0，右移
2q0001□第 3 格写 0，右移
3q0000□第 4 格写 0，右移
4qH000□第 4 格读到 □，停机

共写 3 次。读空白这一步不写纸带。

例题 2｜在末尾追加一个 1（补充）

从左向右扫描，遇到空白就写 1 并停机。转移函数：

δ(q0, 0) = (q0, 0, R)
δ(q0, 1) = (q0, 1, R)
δ(q0, □) = (qH, 1, N)

输入 101□：前两格只读不改，第三格读 1 后右移，第四格读到 □ 写 1 停机，结果为 1011□。

补充说明：写符号可以与读入符号相同，此时表现为“只读不改变纸带”。

课堂练习

  1. 转移函数如下，输入 0000□，求最终纸带、写操作次数、停机状态：
    δ(q0,0)=(q1,1,R)，δ(q1,0)=(q0,1,R)，δ(q0,□)=(qH,□,N)，δ(q1,□)=(qH,□,N)。
  2. 判断正误：图灵机一步可读写多格；读操作改变纸带；写操作覆盖当前格；图灵机一定停机；标准模型每步只移动一格；纸带长度固定。
  3. 把纸带、读写头、状态控制器、转移函数分别类比为简单计算机的哪些部件？
参考答案

1. 纸带最终为 1111□；共写 4 次；在 q0 读到空白后进入 qH 停机。

2. 错、错、对、错、对、错。

3. 纸带 ≈ 主存；读写头 ≈ MAR/MDR 与读写控制；状态控制器 ≈ PC 与控制单元；转移函数 ≈ 指令系统/微程序。注意这是概念类比。

数制与补码

位权 · 补码 · 符号扩展 · 溢出判断

知识要点

  • n 位无符号数范围：0 ~ 2^n − 1；n 位补码范围：−2^(n−1) ~ 2^(n−1) − 1。
  • 求负数补码：各位取反再加 1；补码的补码等于原码。
  • 符号扩展：复制符号位；零扩展只用于无符号数。
  • 溢出判断：同号相加，结果符号相反即溢出。
  • 十六进制与二进制互转：每 4 位一组。
位数无符号范围补码范围
40 ~ 15−8 ~ +7
80 ~ 255−128 ~ +127
160 ~ 65535−32768 ~ +32767

例题

1. 求 −37 的 8 位补码。

37      = 0010 0101
取反    = 1101 1010
加 1    = 1101 1011 = 0xDB

2. 求 0xE6 作为 8 位补码的真值。

1110 0110 → 取反 0001 1001 → 加 1 = 0001 1010 = 26
所以真值为 −26

3. 判断 0x7F + 0x01 是否溢出。

0x7F 是 +127，加 1 得 −128；正 + 正 = 负，溢出。

课堂练习

  1. 写出 4 位补码的 −8、+7、−1。
  2. 0b1101 作为 4 位补码的真值是多少？
  3. 将 0x9C 符号扩展到 16 位。
参考答案

1. −8 = 1000，+7 = 0111，−1 = 1111。

2. 1101 取反加一得 0011，真值为 −3。

3. 0x9C → 0xFF9C。

03

ASCII、Unicode 与 UTF-8

字符集与编码方式 · 码点 · 变长字节序列

知识要点

  • ASCII：标准 7 位，128 个码点；0–31 控制字符，32 空格，48–57 数字，65–90 大写，97–122 小写，127 DEL。
  • Unicode：字符集，码点范围 U+0000 ~ U+10FFFF；汉字常用区 U+4E00 ~ U+9FFF；代理区 U+D800 ~ U+DFFF 不是合法标量值。
  • UTF-8：变长编码，单个码点 1–4 字节，完全兼容 ASCII；后续字节一律以 10 开头。
  • UTF-8 无字节序问题；UTF-16/UTF-32 有大小端和 BOM 问题。
  • 同一个汉字：UTF-8 为 E4 B8 AD，GBK 为 D6 D0；用错编码解码就会乱码。

04

位掩码

AND / OR / XOR / NOT · 提取字段 · 指令译码

知识要点

掩码是一个预先设计好的位模式，用按位运算对数据的某些位进行保留、置位、清零、取反或检测。

目的运算表达式
保留 / 提取ANDx & m
置 1ORx | m
清 0ANDx & ~m
翻转XORx ^ m
检测任一位AND(x & m) != 0
检测全部位AND(x & m) == m
  • 第 k 位掩码：1 << k；低 n 位掩码：(1 << n) − 1。
  • ~ 按字长取反：8 位 ~0x0F = 0xF0，16 位 ~0x0F = 0xFFF0。
  • 清零用 AND NOT，不要用 XOR（XOR 只会翻转）。

例题

1. 指令译码：IR = 0x4A3C，格式为 4 位操作码 + 12 位地址。

IR     = 0100 1010 0011 1100
操作码 = (IR >> 12) & 0xF = 0100 = 0x4
地址   = IR & 0x0FFF     = 1010 0011 1100 = 0xA3C

2. 基本操作：x = 0xB2，m = 0x0F。

运算结果作用
x & m0x02只保留低 4 位
x | m0xBF低 4 位全置 1
x & ~m0xB0低 4 位全清 0
x ^ m0xBD低 4 位翻转

3. ASCII 大小写：'a' = 0x61，0x61 & 0xDF = 0x41 = 'A'；'A' | 0x20 = 'a'。第 5 位（0x20）是大小写位。

课堂练习

  1. 8 位 x = 0x9C，求 x & 0x0F、x | 0x0F、x & ~0x0F、x ^ 0xFF、(x & 0xF0) >> 4。
  2. IR = 0xB7E4，按“4 位操作码 + 12 位地址”求操作码和地址，并写出提取表达式。
  3. 写出：将第 5 位置 1；将第 2 位清 0；检测第 7 位；提取第 4–1 位。
  4. 用掩码把 'G' 转成小写，把 'z' 转成大写。
  5. 说明 8 位和 16 位下 ~0x0F 的值，并解释掩码宽度不匹配的问题。
参考答案

1. 0x0C、0x9F、0x90、0x63、0x9。

2. 操作码 0xB，地址 0x7E4；(IR >> 12) & 0xF、IR & 0x0FFF。

5. 8 位 0xF0，16 位 0xFFF0；宽度不匹配会把不该清的高位一起清掉，或把高位意外置 1。

逻辑门与组合逻辑

真值表 · 加法器 · MUX · 译码器 · 三态门

知识要点

  • 组合逻辑：输出只取决于当前输入，无记忆；真值表、表达式、电路三者可互推。
  • 全加器：S = A ⊕ B ⊕ Cin，Cout = AB + Cin(A ⊕ B)。
  • MUX：用选择端从多路数据中选一路，可实现任意逻辑函数。
  • 译码器：n 个输入产生 2ⁿ 个输出，每个输出对应一个最小项；注意高有效/低有效。
  • 三态门用于总线共享；组合逻辑存在延迟与竞争冒险。

设计流程

  1. 列真值表，确定输入输出。
  2. 写最小项之和，必要时化简。
  3. 选择门电路或 MUX/译码器实现。
  4. 检查延迟、扇出与冒险。

例题

1. 全加器：两个半加器加一个或门。

S    = A ⊕ B ⊕ Cin
Cout = AB + Cin(A ⊕ B)

2. 用 4 选 1 MUX 实现 F = A ⊕ B ⊕ C（选择端 S1S0 = AB）：

F = A'B'C + A'B·C' + AB'·C' + AB·C
I0 = C,  I1 = C',  I2 = C',  I3 = C

当 AB=00 时 F=C；AB=01 或 10 时 F=C'；AB=11 时 F=C。

课堂练习

  1. 化简 F(A,B,C) = Σm(0,1,2,3,4,5)。
  2. 用 3-8 译码器和门电路实现 F = Σm(1,2,4,7)。
  3. 用与非门实现 F = AB + C（提示：两次取反 + 德摩根）。
参考答案

1. F = A' + B'。

2. 高有效译码器的 Y1、Y2、Y4、Y7 接或门；若为低有效输出，则按德摩根用与非门实现。

3. F = ((AB)' · C')'，即两个与非门加一个与非门（或先用与非门得到 (AB)'，再与 C' 与非）。

06

时序逻辑

触发器 · 寄存器 · 计数器 · 有限状态机

知识要点

  • 锁存器电平敏感，触发器边沿敏感；同步设计使用边沿触发。
  • D 触发器特性方程：Q⁺ = D；需满足建立时间和保持时间。
  • 寄存器 = 多个 D 触发器 + 写使能；寄存器堆为双读口、单写口。
  • 计数器、移位寄存器是最常用的时序部件。
  • 状态机设计流程：状态图 → 状态表 → 状态编码 → 次态方程与输出方程。
  • 未使用状态必须处理：复位或设计为自恢复。
部件关键点
D 触发器时钟边沿采样 D，输出 Q
寄存器并行装入，共用写使能
计数器模 N 计数，注意未用状态
移位寄存器串入并出 / 并入串出

例题

4 位右移寄存器，串行输入依次为 1、0、1、1，初值 0000，求 4 个时钟后的值。

初值   0000
输入 1 1000
输入 0 0100
输入 1 1010
输入 1 1101

结果为 1101。

右移时串行输入进入最高位，原各位依次右移。

课堂练习

  1. 用 D 触发器构成 T' 触发器（每个时钟翻转一次），写出连接关系。
  2. 画出“检测连续两个 1”的 Moore 状态图（标出输出）。
  3. 模 6 计数器至少需要几个触发器？状态 6、7 应如何处理？
参考答案

1. D = Q̄，即把 Q 非反馈到 D 端。

2. S0（无 1）→S1（一个 1）→S2（连续两个 1），输出在 S2 为 1；S2 收到 1 保持，收到 0 回 S0。

3. 3 个触发器（0–5）；状态 6、7 通过复位或次态逻辑强制回到 0。

07

主存储器

地址译码 · 读写时序 · 容量扩展 · 层次结构

知识要点

  • 容量 = 2^地址线数 × 字长；地址线决定字数，数据线决定字长。
  • 地址译码 + 片选：字扩展靠片选，位扩展靠芯片并联。
  • 读周期：地址稳定 → CS/OE 有效 → 经过 tAA 数据有效 → 锁存。
  • 写周期：地址与数据建立 → WE 脉冲 → 数据保持。
  • CPU 侧通过 MAR/MDR 访存，经地址、数据、控制三组总线。
  • 存储器慢于 CPU 时插入等待状态。
  • SRAM 快、成本高、不需刷新；DRAM 需刷新；两者均易失。
比较项SRAMDRAM
单元6T 触发器1T1C 电容
速度快较慢
刷新不需要需要
成本高低
易失性易失易失

例题

1. 用 1K×8 芯片构成 4K×16 存储器。

芯片数 = (4K×16) / (1K×8) = 8 片
组织：2 片并联完成位扩展（1K×16），共 4 组完成字扩展
地址：A9–A0 接片内；A11–A10 经 2-4 译码器产生组选
      同组两片 CS 并联

2. 存储器 tAA = 70 ns，CPU 时钟周期 50 ns。

⌈70/50⌉ − 1 = 1 个等待状态
实际访问周期 = 100 ns

课堂练习

  1. 16 根地址线、32 位字长，存储容量是多少字节？
  2. 用 2K×8 芯片构成 8K×32 存储器，需要多少片？地址如何分组？
  3. SRAM 与 DRAM 哪个需要刷新？掉电后数据是否保留？
  4. 写出一次读周期的关键信号顺序。
参考答案

1. 2^16 × 4 B = 256 KB。

2. 16 片；4 片位扩展为 2K×32，4 组字扩展；A10–A0 接片内，A12–A11 经 2-4 译码器选择组。

3. DRAM 需要刷新；两者掉电后数据都丢失。

4. 地址稳定 → 片选/读使能有效 → 等待 tAA → 数据有效 → 锁存。

08

CPU 数据通路与微操作

寄存器 · 单总线 · ALU · RTL 微操作

知识要点

寄存器作用
PC下一条指令地址
IR当前指令
MAR访存地址
MDR访存数据
AC累加器，参与运算
FLAGS零/负/进位等标志
  • 单总线结构：一个节拍只能有一个驱动源，靠三态门避免冲突。
  • RTL 记法：MAR ← PC、MDR ← M[MAR]、AC ← AC + MDR。
  • ALU 的控制信号决定执行何种运算。
  • 数据通路决定指令集：没有相应硬件就没有相应指令。
  • 多周期控制：一个或一组不冲突的微操作占一个节拍。

例题｜ADD addr 的微操作

T0: MAR ← PC
T1: MDR ← M[MAR]；PC ← PC + 1
T2: IR ← MDR
T3: MAR ← IR[11:0]
T4: MDR ← M[MAR]
T5: AC ← AC + MDR

若 PC 自增也走 ALU 和总线，T1 需拆成两拍；以上按“PC 有独立自增通路”处理。

交互演示｜取指数据通路

点击“运行取指”：PC → MAR → 主存 → MDR → IR → 控制单元。

课堂练习

  1. 写出 STORE addr 的微操作（取指后）。
  2. 写出 JZ addr 的微操作，并指出哪些节拍使用地址总线。
  3. 为什么单总线机器一拍内不能同时执行 MAR ← PC 和 AC ← MDR？
参考答案

1. T3: MAR ← IR[11:0]；T4: MDR ← AC；T5: M[MAR] ← MDR（MemWrite）。

2. T3: if AC = 0 then PC ← IR[11:0]；取指阶段 T0、T1 使用地址总线，T3 访存也使用地址总线；JZ 执行阶段不使用地址总线。

3. 两个源同时驱动总线会造成冲突，单总线一拍只允许一个驱动源。

指令周期与控制单元

取指—译码—执行 · 控制信号 · 单周期 vs 多周期

知识要点

  • 指令周期：取指 → 译码 → 执行（→ 中断）。
  • 取指阶段的微操作与具体指令无关，是指令的公共前缀。
  • 控制单元实现方式：硬布线（组合逻辑或状态机）与微程序。
  • 控制信号分类：寄存器打入、寄存器输出、存储器读/写、ALU 操作、PC 更新。
  • 单周期：CPI = 1，但时钟周期取决于最慢指令。
  • 多周期：时钟周期短、硬件复用，但 CPI > 1、控制更复杂。
  • 关键路径决定最高主频。

2. 单周期 CPI = 1、控制简单，但时钟周期由最慢指令决定，硬件冗余大；多周期时钟短、硬件复用，但 CPI > 1、控制复杂。

3. 1 / 8 ns = 125 MHz。

指令集与汇编

指令格式 · 寻址 · 程序跟踪 · 软硬件接口

知识要点

  • 指令格式：4 位操作码 + 12 位地址，地址字段给出操作数地址。
  • 直接寻址为主；立即、间接、变址可作为扩展。
  • 汇编到机器码：查操作码表，符号表回填地址。
  • 程序跟踪方法：维护 PC、AC、目标内存三列，逐条更新。
  • 标志位由 ALU 结果产生，条件跳转读取标志。
  • PC 保存的是“下一条指令的地址”，指令内容在内存中。

例题｜跟踪程序

        LOAD  X
        ADD   Y
        STORE Z
        JZ    DONE
        LOAD  Y
        STORE Z
DONE:   HALT
X:      DEC   6
Y:      DEC   -6
Z:      DEC   0

Y = −6 时：AC = 6 → ADD 后 AC = 0，ZF = 1 → Z = 0 → JZ 成立，跳到 HALT；最终 Z = 0。

Y = −5 时：AC = 1，JZ 不成立 → LOAD Y 得 AC = −5 → Z = −5 → HALT。

性能分析

执行时间 · CPI · 主频 · Amdahl 定律

知识要点

  • 执行时间：T = I × CPI × Tclk = I × CPI / f。
  • CPI 是各类指令 CPI 的加权平均，不是算术平均。
  • 主频提高可能带来 CPI 上升（访存、流水线），要综合判断。
  • Amdahl 定律：加速比受未优化部分限制。
  • 内存墙：CPU 与 DRAM 的速度差距持续扩大。

例题

程序共 2×10⁶ 条指令：ALU 50%（CPI 1）、访存 30%（CPI 4）、分支 20%（CPI 2），主频 1 GHz。

CPI = 0.5×1 + 0.3×4 + 0.2×2 = 2.1
T   = 2×10⁶ × 2.1 / 1×10⁹ = 4.2 ms

若主频提升到 1.5 GHz，但访存 CPI 变为 5：

CPI = 0.5×1 + 0.3×5 + 0.2×2 = 2.4
T   = 2×10⁶ × 2.4 / 1.5×10⁹ = 3.2 ms
加速比 = 4.2 / 3.2 ≈ 1.31

小工具｜执行时间计算

T = I × CPI / f
T = 4.200 ms

课堂练习

  1. I = 10⁶ 条，CPI = 3，主频 2 GHz，求执行时间。
  2. 优化后指令数减少 20%，CPI 升到 3.5，主频不变，求执行时间和加速比。
  3. 某部分占总时间 40%，该部分加速 5 倍，求总加速比。
参考答案

1. T = 10⁶ × 3 / 2×10⁹ = 1.5 ms。

2. T = 0.8×10⁶ × 3.5 / 2×10⁹ = 1.4 ms；加速比 1.5 / 1.4 ≈ 1.07。

3. 1 / (0.6 + 0.4/5) = 1 / 0.68 ≈ 1.47。

综合题：三输入多数表决器

真值表 · 最小项之和 · 最简与或 · 卡诺图

题目

有 A、B、C 三个输入信号，若 A、B、C 中有两个或两个以上为 1，则输出 F 为 1，其余情况 F 为 0。

  1. 写出完整的真值表；
  2. 写出函数的最小项之和表达式，以及最简与或表达式。

（1）真值表

最小项ABCF
m00000
m10010
m20100
m30111
m41000
m51011
m61101
m71111

实时验证

F = 0

（2）表达式与化简

最小项之和：

F = Σm(3, 5, 6, 7)
  = A'BC + AB'C + ABC' + ABC

化简：

  • m3 + m7：A'BC + ABC = BC
  • m5 + m7：AB'C + ABC = AC
  • m6 + m7：ABC' + ABC = AB

最简与或表达式：

F = AB + AC + BC

最小性：(1,1,0) 只被 AB 覆盖，(1,0,1) 只被 AC 覆盖，(0,1,1) 只被 BC 覆盖，所以三项都不可删除；最简式为 3 项、6 个文字。

注意：不能把 BC 当作冗余项消去。共识定理要求两个项含互补文字（如 AB + A'C），这里不满足。

卡诺图验证

点击按钮，观察 m7 被三个圈共用。
A \ BC00011110
00010
10111

三个圈分别对应 BC（m3、m7）、AC（m5、m7）、AB（m6、m7）。

变式练习

将条件改为“A、B、C 中恰有两个为 1 时输出 F 为 1”，重新写出：

  1. 真值表中有哪些最小项为 1？
  2. 最小项之和表达式；
  3. 最简与或表达式。
参考答案

1. m3、m5、m6（011、101、110）。

2. F = Σm(3,5,6) = A'BC + AB'C + ABC'。

3. 三个最小项两两不相邻，无法合并，最简与或式就是 A'BC + AB'C + ABC'（3 项、6 个文字）。

第 1 题

假如一台计算机有 8 个数据寄存器（R0~R7），512 个字的存储空间以及 16 种不同的指令（如 add，subtract 等），那么下面这条指令需要占 位空间。

参考答案与解析

高频易错点

考前最后一遍自检

01图灵机一步不能读写多格；读不改变纸带，写才覆盖。
02图灵机不一定停机，纸带无界；不要与真实内存混淆。
03补码溢出看符号是否异常，不看最高位进位。
04Unicode 是字符集，UTF-8 是编码；ASCII 标准是 7 位 128 个码点。
05UTF-8 续字节以 10 开头，不能当首字节；字符数不等于字节数。
06掩码宽度要与字长一致；~ 的结果随字长变化。
07清零用 AND NOT，不要用 XOR；XOR 只翻转。
08组合逻辑无记忆；寄存器/触发器才有状态。
09容量 = 2^地址线数 × 字长；片选决定字扩展。
10单总线一拍只能一个驱动源；PC 存地址而非指令内容。
11CPI 要加权平均；主频提高不一定更快。
12多数表决器的 BC 不是冗余项，三项都不能删。
