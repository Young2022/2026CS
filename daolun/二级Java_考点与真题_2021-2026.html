Java 语言特点与体系结构

理论 · 选择题为主

大纲要求掌握 Java 语言的特点、实现机制和体系结构：为什么 Java 能"一次编写、到处运行"？源文件如何变成可执行程序？JDK / JRE / JVM 之间是什么关系？

Java 语言的主要特点

  • 面向对象——封装、继承、多态，一切皆对象
  • 平台无关（可移植性）——编译生成字节码，由 JVM 解释执行，与操作系统/硬件"分开"
  • 安全性——无指针操作、自动内存管理（垃圾回收），Applet 沙箱机制
  • 健壮性——强类型、异常处理机制
  • 多线程——内置线程支持
  • 自动垃圾回收——程序员无需手工释放内存（Java 要求编程者管理内存 是错误说法）

实现机制：从源码到运行

Test.java 源文件
↓ javac 编译
Test.class 字节码
↓ java 启动 JVM
JVM 解释/即时编译执行
考点：Java 字节码与各操作系统及硬件之间的关系是"分开"的——字节码不针对任何具体平台，由不同平台上的 JVM 解释执行，这正是可移植性的来源（官方样题）。

体系结构：JDK / JRE / JVM

组成包含关系说明
JDK开发工具包包含 JRE + 编译器 javac + 调试工具，供开发使用
JRE运行环境包含 JVM + 类库，供运行 .class 程序使用
JVM虚拟机解释执行字节码，屏蔽底层平台差异

Java 程序结构（必背）

JAVA// 源文件名必须与 public 类名一致：Test.java
public class Test {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
// 运行：javac Test.java  →  java Test（不带 .class 后缀）
高频判断题：① 一个源文件最多只能有一个 public 类；② 源文件名与 public 类名必须相同；③ Java 严格区分大小写；④ 源文件扩展名是 .java，编译后是 .class（不是 .jar / .html / .exe）。

基本数据类型与运算符

选择题高频 · ★★★★★

大纲要求：变量和常量、基本数据类型及转换、包装类、运算符和表达式运算、字符串和数组、注释。这一章是全部选择题的基础，务必滚瓜烂熟。

标识符与关键字

  • 组成：字母 / 下划线 _ / 美元符 $ 开头，后续可含数字；不能以数字开头
  • 不能与关键字重名（如 class、super、do）；区分大小写
  • 命名约定：类名首字母大写（PascalCase）；变量、方法名首字母小写（camelCase）；常量名全大写（官方样题）
  • 合法：_object、$123、fieldname；不合法：3number、#number、do、super

Java 为 8 种基本类型提供包装类：Integer / Double / Boolean / Character / Byte / Short / Long / Float，用于把基本类型包装成对象；自动装箱/拆箱（JDK 5+）。

运算符与表达式（易错点集中地）

JAVA// 算术：+ - * / %（取余）；整数除法结果仍为整数
System.out.println(100 % 3);    // 1
System.out.println(100 % 3.0);  // 1.0（float/double 参与 → 结果浮点）

// 关系：==  !=  >  <  >=  <=（= 是赋值，不是关系运算符）
// 逻辑：&&  ||  !   短路求值
// 位运算：&  |  ^  ~  <<  >>  >>>
System.out.println(8 >> 1);      // 4（右移一位，相当于整除 2）

// 三元：条件 ? 表达式1 : 表达式2
System.out.println(3 > 2 ? 4 : 5);  // 4

// 扩展赋值：+=  -=  *=  /=  %=（是表达式语句）
int b = 5;  b *= 2;     // b = 10
易错点：① 字符串拼接 "xyz" + 3 + 4 + 5 结果是 "xyz345"（从左到右先拼字符串）；② b#a; 不是合法表达式语句；③ 运算符优先级中 ++ / -- 最高，?: 是唯一三元运算符，优先级低于多数运算符。

进制字面量

  • 八进制：以 0 开头，如 0144（十进制 100）
  • 十六进制：以 0X / 0x 开头，如 0XA6；科学计数法：-1E3 = −1000.0

嵌套循环计算（考试最爱）

JAVAint s = 0;

面向对象基础：类、对象、构造方法

核心中的核心 · ★★★★★

面向对象是 Java 的灵魂。大纲要求：OOP 基本概念和特征、类的基本组成、对象的生成/使用/删除、包与接口、常用类。

类与对象

JAVAclass Student {
    // 属性（成员变量 / 字段）
    private String name;
    private int age;

    // 构造方法：与类同名、无返回值（也不写 void）
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
    // 方法（行为）
    void show() { System.out.println(name + "," + age); }
}

// 创建对象：new 调用构造方法，返回对象引用
Student s = new Student("张三", 20);
s.show();

构造方法四大规定（官方样题）

  • 构造方法名与类名必须相同
  • 没有返回值，且不用 void 声明
  • 可以重载（多个不同参数的构造方法）
  • 只能通过 new 自动调用（不能手动调用）

this 与 super

JAVAclass Animal {
    public Animal() { System.out.print("animal"); }
    public Animal(int n) {
        this();                    // this() 调用本类无参构造
        System.out.print("=" + n);
    }
}
class Dog extends Animal {
    public Dog() {
        super(12);                 // super() 调用父类构造
        System.out.println(" dog");
    }
}
// new Dog() 输出：animal=12 dog（先父类后子类）

封装与访问控制

修饰符同类同包子类（不同包）所有类
private✔
默认（包访问）✔✔
protected✔✔✔
public✔✔✔✔
记忆：访问范围从小到大 private → 默认 → protected → public。 子类不能访问父类的 private 成员（官方样题：子类不能进行的操作是"访问父类私有属性"）。 封装 = private 属性 + public 的 getter/setter。

static 与 final 关键字

JAVAclass Util {
    static int count = 0;          // 静态变量：属于类，所有对象共享
    static void run() { ... }     // 静态方法：属于类，不能直接使用 this
}
// final 类不能被继承；final 方法不能覆盖；final 变量是常量
final class String { }          // String、System 都是 final 类
final double PI = 3.14159;     // 常量：全大写命名（官方样题）

继承、多态与接口

选择+操作核心 · ★★★★★

大纲要求：继承、多态和高级类特性、覆盖与重载、抽象类、接口、内部类、枚举。操作题的类设计填空集中在这块。

继承（extends）

JAVAclass Animal {
    void sound() { System.out.println("..."); }
}
class Dog extends Animal {
    @Override
    void sound() { System.out.println("汪"); }   // 覆盖（重写）
    void bark() { System.out.println("汪汪"); }  // 子类新增方法
}
  • 覆盖（Override）：子类重新实现父类方法，方法签名一致、访问权限不能缩小、可用 @Override 检查
  • 重载（Overload）：同一个类中方法名相同，参数个数/类型/顺序不同；不能只靠返回类型区分
  • 子类可覆盖父类方法、增加方法、增加属性；不能访问父类 private 成员
  • Java 单继承：一个类只能直接继承一个父类

多态：父类引用指向子类对象

JAVAAnimal a = new Dog();    // 向上转型：父类引用指向子类对象
a.sound();                     // 运行期动态绑定，调用 Dog 的 sound()
// 子类对象可以作为父类对象使用（真题原句）

抽象类与接口（高频对比考点）

对比抽象类 abstract class接口 interface
声明abstract class Animalinterface Flyable
方法可有抽象方法 + 普通方法方法隐式为 public abstract（JDK8+ 可有 default/static）
字段可定义成员变量隐式为 public static final 常量
实例化不能直接 new不能直接 new
使用子类 extends 继承（单继承）implements 实现，可多实现
JAVA// 抽象类：不能实例化，抽象方法子类必须实现
abstract class Shape {
    abstract double area();          // 抽象方法，无方法体
    void info() { }                   // 普通方法可以有方法体
}
class Circle extends Shape {
    double area() { return 0; }   // 必须实现抽象方法
}

// 接口：implements 实现，一个类可实现多个接口
interface Flyable {
    void fly();
}
class Bird implements Flyable {
    public void fly() { }          // 实现方法必须 public
}
易错：抽象方法不能有方法体 {}；普通类不能声明抽象方法；接口中的方法若写成带方法体（非 default）则编译错误。

异常处理与断言

操作题综合应用核心 · ★★★★★

大纲要求：异常处理（捕获、声明抛出、自定义异常）和断言概念。综合应用题通常就是"输入两个整数做除法 + 异常处理 + GUI 显示结果"。

异常体系

Throwable（所有可抛出对象）
│
Error（系统级，如 OutOfMemoryError）
Exception（可处理）→ RuntimeException（运行时）与其他（受检）
  • 常见运行时异常：ArithmeticException（除零）、NullPointerException（空指针）、ArrayIndexOutOfBoundsException（下标越界）、NumberFormatException（数字格式）
  • 受检异常：IOException 等，必须捕获或在方法签名 throws 声明
  • 自定义异常：继承 Exception（官方样题：父类可以是 Exception）

try-catch-finally 与抛出

JAVAtry {
    int r = 10 / 0;                // 抛出 ArithmeticException
} catch (ArithmeticException e) {      // 子类异常在前
    System.out.println("除零错误");
} catch (Exception e) {               // 父类异常在后
    System.out.println("其他错误");
} finally {                            // 无论是否异常都执行
    System.out.println("收尾");
}

// 声明抛出：方法可能抛出异常但不处理，用 throws 交给调用者
public double quotient(int a, int b) throws Exception {
    if (b == 0) throw new Exception();   // throw 手动抛出异常对象
    return a / b;
}
规则：① 多重 catch 必须子类在前、父类在后；② finally 无论是否异常都会执行（真题考点）；③ throw 抛出异常对象，throws 声明可能抛出的异常。

断言 assert

JAVAassert a > 0 : "a 必须为正数";   // 条件为 false 时抛出 AssertionError
// 运行需加参数启用：java -ea Test（默认不启用）

线程与同步

选择题高频 · ★★★★

大纲要求：线程的概念、线程的基本控制（Thread / Runnable）、同步机制（synchronized / wait / notify）。

创建线程的两种方式

JAVA// 方式一：继承 Thread 类，重写 run()
class T1 extends Thread {
    public void run() { System.out.println("T1"); }
}

// 方式二：实现 Runnable 接口（推荐，避免单继承限制）
class T2 implements Runnable {
    public void run() { System.out.println("T2"); }
}

// 启动线程必须调用 start()，而不是直接调 run()
new T1().start();
new Thread(new T2()).start();
官方样题：重写 run() 时方法签名必须完全一致——若写成 public void run(Thread t)，只是重载而非覆盖，程序编译错误（Thread 的 run() 无参）。

JAVApublic static int factorial(int n) {
    int f = 1;
    for (int i = 1; i <= n; i++)
        f *= i;                  // 填空处：f = f * i
    return f;
}
public static void main(String[] args) {
    System.out.println(factorial(6));   // 输出 720
