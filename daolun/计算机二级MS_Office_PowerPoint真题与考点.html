三、教育部教育考试院公开"样题"原题

以下题目来自教育部教育考试院公开发布的《全国计算机等级考试（NCRE）二级MS Office高级应用与设计样题及参考答案》中 PowerPoint 部分的代表性题目。为尊重版权，这里保留必要题干用于学习，并提供官方原始资料入口。

原题 1｜幻灯片母版母版

关于 PowerPoint 2016 幻灯片母版的说法，正确的是：

A）母版只能在第一张幻灯片上修改。
B）母版决定了幻灯片的统一外观，包括字体、背景和占位符。
C）一张幻灯片只能对应一个母版，且不能删除。
D）母版修改后，未应用该母版的幻灯片也会同步更新。

参考答案：B。母版用于统一控制幻灯片外观；可有多张母版，但每张幻灯片使用且仅使用一个母版。
原题 2｜超链接超链接

在 PowerPoint 2016 中，要让幻灯片放映时点击某对象跳转到第 5 张幻灯片，应使用：

A）动画 → 路径动画　　B）切换 → 自动换片
C）插入 → 超链接 → 链接到本文档中的位置　　D）幻灯片放映 → 自定义放映

参考答案：C。"超链接"可指定跳转到指定幻灯片、文件或网页。
原题 3｜动画与切换动画切换

PowerPoint 2016 中，"切换"选项卡设置的是：

A）幻灯片中文本出现的顺序。
B）幻灯片与幻灯片之间过渡时的动画效果。
C）同一张幻灯片内不同对象的进入方式。
D）幻灯片放映时的排练计时。

参考答案：B。"切换"控制幻灯片之间的过渡；"动画"控制同一张幻灯片内对象的出现方式。

📅 2025 年代表性 PPT 大题 · 制作"人工智能主题演讲"

题号：2025-P12025年主题与母版

题干：打开"AI演讲.pptx"，请按下列要求完成操作：

  1. 将演示文稿主题设置为"柏林"，颜色变体选择第三种。
  2. 编辑母版：在母版的右下角插入一个圆形动作按钮"返回第一张"，设置超链接到幻灯片 1。
  3. 为所有幻灯片添加自动更新的日期（页脚），并在标题幻灯片（即第 1 张）不显示页脚。
  4. 将所有幻灯片背景填充设置为"白色，背景 1，深色 5%"。
  5. 插入一张新幻灯片置于末尾，版式选择"标题和内容"，标题为"谢谢观看"。
参考答案（操作思路）：
  1. "设计 → 主题 → 柏林"；"颜色 → 第 3 种颜色变体"。
  2. "视图 → 幻灯片母版" → 在母版右下角"插入 → 形状 → 动作按钮（第一项：返回）"；右键"超链接 → 幻灯片 1"。
  3. "插入 → 页眉和页脚"，勾选"日期和时间 → 自动更新"，勾选"标题幻灯片中不显示"；"全部应用"。
  4. "设计 → 设置背景格式 → 纯色填充"，选"白色，背景 1，深色 5%"；"应用于全部"。
  5. 末尾右键"新建幻灯片"；选"标题和内容"版式；输入"谢谢观看"。
核心能力：主题、母版编辑、动作按钮、页脚设置、背景应用。
题号：2025-P22025年动画与切换

题干：对"AI演讲.pptx"添加动画与切换：

  1. 为第 2 张幻灯片中所有正文项目添加"浮入"进入动画；动画顺序按项目顺序；每项延时 0.5 秒。
  2. 为第 3 张幻灯片中的图片添加"脉冲"强调动画，并设置在上一项之后自动开始。
  3. 为所有幻灯片设置"推入"切换效果，方向"从右"；"推进"时长 1 秒。
  4. 设置第 1 张幻灯片切换时不发出声音、单击鼠标切换。
参考答案（操作思路）：
  1. 选中第 2 张幻灯片正文项目 → "动画 → 添加动画 → 进入 → 浮入"；"动画 → 持续时间 1 秒"；"动画 → 计时 → 延迟 0.5 秒"。
  2. 选中图片 → "动画 → 添加动画 → 强调 → 脉冲"；"开始"改为"上一动画之后"。
  3. 选中所有幻灯片（Ctrl+A）→ "切换 → 推入（从右）"；"持续时间 1 秒"。
  4. 选中第 1 张 → "切换 → 声音 → 无声音"；"换片方式 → 单击鼠标时"。
核心能力：多对象动画、动画计时、切换效果与声音。

📅 2024 年代表性 PPT 大题 · 制作"公司年度汇报演示"

题号：2024-P12024年SmartArt与图表

题干：打开"年度汇报.pptx"，请完成：

  1. 将第 3 张幻灯片中的项目列表转换为 SmartArt"层次结构"。
  2. 为 SmartArt 整体应用"彩色范围 — 强调 1"样式。
  3. 在第 5 张幻灯片中插入一张"簇状柱形图"，展示 2020–2024 年公司营收（数据自定义）。
  4. 为图表添加标题"近5年营收对比"；隐藏图例。
  5. 将第 5 张幻灯片中图片的动画效果设为"擦除（自顶部）"。
参考答案（操作思路）：
  1. 选中第 3 张幻灯片项目文本 → "开始 → 转换为 SmartArt → 层次结构"。
  2. 选中 SmartArt → "SmartArt 设计 → 更改颜色 → 彩色范围 — 强调 1"。
  3. 第 5 张 → "插入 → 图表 → 簇状柱形图"，录入 2020–2024 数据。
  4. "图表工具 → 设计 → 添加图表元素 → 图表标题"输入"近5年营收对比"；"图例 → 无"。
  5. 选中图片 → "动画 → 添加入场 → 擦除（自顶部）"。
核心能力：文本转 SmartArt、动画与图表编辑。
题号：2024-P22024年超链接与动作

题干：对"年度汇报.pptx"完善交互：

  1. 在第 1 张幻灯片上添加三个文本框："公司业绩""发展回顾""未来展望"，分别链接到第 3、第 5、第 7 张幻灯片。
  2. 在所有幻灯片右下角添加动作按钮"第一张"，链接到第 1 张幻灯片。
  3. 设置自定义放映"汇报摘要"，仅包含第 1、3、5 张。
  4. 放映类型设为"演讲者放映（全屏）"；勾选"循环播放，按 Esc 键终止"。
参考答案（操作思路）：
  1. 插入 3 个文本框，输入文字 → 选中 → "插入 → 链接 → 超链接 → 本文档中的位置"，分别选 3、5、7。
  2. "插入 → 形状 → 动作按钮（第一项：第一张）"，在右下角绘制；右键"超链接 → 幻灯片 1"。"全部应用"可选。
  3. "幻灯片放映 → 自定义放映 → 新建"，名称"汇报摘要"，添加 1、3、5 张。
  4. "幻灯片放映 → 设置放映方式"，类型"演讲者放映（全屏）"；勾选"循环放映，按 Esc 键终止"。
核心能力：超链接、动作按钮、自定义放映、放映参数。

📅 2023 年代表性 PPT 大题 · 制作"产品发布会演示"

题号：2023-P12023年版式与母版

题干：打开"产品发布会.pptx"，请完成：

  1. 将演示文稿版式整体更换为"标题幻灯片"版式（封面页），其余页面统一使用"标题和内容"。
  2. 在母版中插入公司 LOGO 图片（占位符位于左上角），设置仅在非标题幻灯片中显示。
  3. 设置标题幻灯片（第 1 张）背景为"白色"，其他幻灯片背景为"白色，背景 1，深色 25%"。
  4. 使用节(Section)将演示文稿分为"开场 / 产品介绍 / 价格与总结"三节，并将节重命名。
参考答案（操作思路）：
  1. 选中第 1 张 → "版式 → 标题幻灯片"；其余幻灯片选中 → "版式 → 标题和内容"。
  2. "视图 → 幻灯片母版" → 在母版左上角"插入 → 图片"；"格式 → 排列 → 对齐（左/上）"；在"幻灯片母版"工具栏勾选"在标题幻灯片中隐藏"。
  3. 选中第 1 张 → "设计 → 设置背景格式 → 纯色 → 白色"；其他幻灯片选中 → "设计 → 设置背景格式 → 纯色 → 深色 25%"。
  4. "开始 → 节 → 新增节"；右键节标题重命名为"开场""产品介绍""价格与总结"；将幻灯片拖到对应节。
核心能力：版式、母版图片与可见性、节管理。
题号：2023-P22023年多媒体与导出

题干：完善多媒体与导出：

  1. 在第 2 张幻灯片插入音频文件"bgm.mp3"，设置为"在后台播放、跨幻灯片播放"。
  2. 在第 6 张幻灯片插入视频"产品演示.mp4"，单击时自动播放。
  3. 将演示文稿导出为 MP4 视频，演讲者备注全部保留。
  4. 将演示文稿另存为"产品发布会-PDF.pdf"，保留幻灯片备注。
参考答案（操作思路）：
  1. "插入 → 音频 → 此设备 → bgm.mp3"；选中喇叭图标 → "播放 → 在后台播放"；"音频工具 → 播放 → 跨幻灯片播放"。
  2. "插入 → 视频 → 此设备 → 产品演示.mp4"；选中视频 → "播放 → 单击时开始"。
  3. "文件 → 导出 → 创建视频"，勾选"使用已录制的旁白和计时"，导出 MP4。
  4. "文件 → 另存为 → PDF"，选项"发布选项"中勾选"备注"。
核心能力：音视频插入、后台播放、导出视频与 PDF。

📅 2022 年代表性 PPT 大题 · 制作"教学培训课件"

题号：2022-P12022年版式与基础编辑

题干：打开"教学课件.pptx"，请完成：

  1. 新增 3 张幻灯片，分别采用"标题幻灯片""标题和内容""节标题"版式，并填写标题"课程介绍""目录""总结"。
  2. 对全部幻灯片应用主题"奥斯汀"；设置标题幻灯片的标题字体为"微软雅黑"、48 号、加粗。
  3. 将"目录"幻灯片中的"第一章""第二章""第三章"分别超链接到第 3、5、7 张幻灯片。
  4. 将所有幻灯片页面尺寸设置为"宽屏 16:9"。
  5. 为全部幻灯片添加幻灯片编号。
参考答案（操作思路）：
  1. "开始 → 新建幻灯片"，依次选择"标题幻灯片""标题和内容""节标题"，分别填入标题。
  2. "设计 → 主题 → 奥斯汀"；选中第 1 张的标题文本 → "字体" 设置微软雅黑、48、加粗。
  3. 在"目录"幻灯片输入文本 → 选中"第一章" → "插入 → 链接 → 超链接 → 本文档中的位置 → 3"。其余两项同理。
  4. "设计 → 幻灯片大小 → 宽屏 16:9"。
  5. "插入 → 页眉和页脚"，勾选"幻灯片编号"；"全部应用"。
核心能力：新建幻灯片、版式、主题、超链接、页面尺寸、页脚。
题号：2022-P22022年动画与切换

题干：完善动画与切换：

  1. 为"目录"幻灯片中的项目依次添加"淡出"进入动画；单击鼠标依次出现。
  2. 为第 4 张幻灯片的图片设置"陀螺旋"强调动画，"持续时间 3 秒"，"重复 2 次"。
  3. 为全部幻灯片设置"淡出"切换效果，时长 0.8 秒。
  4. 使用"排练计时"自动记录每张幻灯片的播放时间，并将文件另存为"教学课件-计时版.pptx"。
参考答案（操作思路）：
  1. 选中第 1 项 → "动画 → 淡出"；后续项同样；动画"开始"设为"单击时"。
  2. 选中图片 → "动画 → 陀螺旋"；"动画 → 持续时间 3 秒"；"动画 → 重复 2 次"。
  3. 选中所有幻灯片 → "切换 → 淡出"；"持续时间 0.8 秒"。
  4. "幻灯片放映 → 排练计时"；逐张演示直至最后；"是"保存计时；"另存为"。
核心能力：多对象动画、计时动画、切换、排练计时。

📅 2021 年代表性 PPT 大题 · 制作"工作汇报演示"

题号：2021-P12021年主题、母版与表格

题干：打开"工作汇报.pptx"，请完成：

  1. 应用主题"离子"；将所有幻灯片背景填充为"浅灰色"。
  2. 编辑母版：在底部居中插入占位符文字"汇报人：张三 日期：2021-12-01"。
  3. 在第 4 张幻灯片插入一个 4 行 5 列的表格，输入月度数据。
  4. 设置第 4 张幻灯片中表格的"内置中等样式 2 — 强调 6"。
  5. 将演示文稿以"工作汇报-打印版.pdf"另存，保留备注。
参考答案（操作思路）：
  1. "设计 → 主题 → 离子"；"设计 → 设置背景格式 → 纯色填充 → 浅灰色"；"全部应用"。
  2. "视图 → 幻灯片母版"；在底部"插入 → 文本框"，输入文字并居中；"关闭母版视图"。
  3. "插入 → 表格 → 4×5"，输入数据。
  4. "表工具 → 设计 → 内置中等样式 2 — 强调 6"。
