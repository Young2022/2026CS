原题 1｜表格数据粘贴Word表格

Word 2016 文档中有一个 5 行×4 列的表格，如果要将另外一个文本文件中的 5 行文字拷贝到该表格中，并且使其正好成为该表格一列的内容，最优的操作方法是：

A）复制5行文字后，将光标置于指定列的第一个单元格，再粘贴。
B）将5行文字一行一行复制、粘贴到对应的5个单元格。
C）复制5行文字后，选中对应列的5个单元格，再粘贴。
D）复制5行文字后，选中整个表格再粘贴。

参考答案：C。考查Word表格中批量粘贴文本到多个单元格的操作。
原题 2｜修订功能审阅与修订

张经理在对 Word 2016 文档格式的工作报告修改过程中，希望在原始文档显示其修改的内容和状态，最优的操作方法是：

A）利用批注功能，为每一处需要修改的位置添加批注。
B）利用插入选项卡的文本功能添加文档部件。
C）利用"审阅"选项卡的修订功能，选择带"显示标记"的文档修订查看方式后，在文档中直接修改。
D）利用插入选项卡的修订标记功能插入修订符号。

参考答案：C。考查"修订"与"批注"的区别。
原题 3｜分节与页码分节符

小华利用 Word 2016 编辑一份书稿，出版社要求目录和正文的页码分别采用不同的格式，且均从第1页开始。最优的操作方法是：

A）将目录和正文分别存在两个文档中，分别设置页码。
B）在目录与正文之间插入分节符，在不同的节中设置不同的页码。

参考答案：B。核心考点是"分节符"能够使不同节具有独立的页面设置和页码格式。

📅 2025 年代表性 Word 大题 · 制作"人工智能产品介绍手册"

题号：2025-W12025年综合排版

题干：打开素材文件"产品介绍.docx"，按下列要求完成操作：

  1. 页面设置：纸张 A4、纵向；上、下页边距 2.5 cm，左页边距 3 cm，右页边距 2 cm。
  2. 样式设置：将"产品介绍"应用为"标题1"样式；"功能特点""应用场景""技术参数"等应用为"标题2"样式；正文设置为宋体、小四号。
  3. 段落格式：正文段落首行缩进 2 字符，行距 1.5 倍行距，段后间距 0.5 行。
  4. 插入表格：在"技术参数"下方插入一个 4 行 3 列的表格，并输入相应参数。
  5. 插入图片：在"应用场景"上方插入一张图片，环绕方式设置为"四周型"。
  6. 页眉页脚：插入页眉"产品介绍手册"；页脚居中插入页码，首页不显示页码。
  7. 自动目录：在文档最前面插入自动目录，显示前两级标题。
参考答案（操作思路）：
  1. "布局 → 页面设置"：A4 纵向，页边距如题。
  2. "开始 → 样式"：依次应用标题1、标题2；正文设为宋体小四。
  3. "开始 → 段落"：特殊格式首行缩进 2 字符，行距 1.5 倍行距，段后 0.5 行。
  4. "插入 → 表格"：4×3 表格，输入参数内容。
  5. "插入 → 图片 → 此设备"，选中图片后"图片格式 → 环绕四周型"。
  6. "插入 → 页眉"，输入文字；"插入 → 页码 → 页面底端 → 居中"；勾选"首页不同"。
  7. "引用 → 目录 → 自动目录1"；如正文有修改，右键"更新整个目录"。
核心能力：页面设置、样式、段落、图片环绕、页眉页脚、自动目录。
题号：2025-W22025年邮件合并

题干：使用邮件合并功能，根据 Excel 数据源"客户名单.xlsx"为每位客户生成邀请函：

  1. 在 Word 中新建文档作为主文档。
  2. 将"客户名单.xlsx"作为数据源连接，字段包括"姓名""性别""公司"。
  3. 在主文档中插入合并字段：{{姓名}}、{{性别(先生/女士)}}、{{公司}}。
  4. 对正文使用"如果…那么…否则…"域，使称呼根据性别变化。
  5. 合并所有记录后，保存为"客户邀请函-合并结果.docx"。
参考答案（操作思路）：
  1. "邮件 → 开始邮件合并 → 信函"。
  2. "选择收件人 → 使用现有列表"：选择"客户名单.xlsx"作为数据源。
  3. "插入合并字段"，依次插入姓名、性别、公司。
  4. "插入 Word 域 → IF…"，比较{MERGEFIELD 性别}="男"输出"先生"否则"女士"。
  5. "完成并合并 → 编辑单个文档 → 全部"，再"另存为"。
核心能力：邮件合并、数据源连接、IF 域判断。

📅 2024 年代表性 Word 大题 · 制作"校园活动总结报告"

  2. "开始 → 样式"：标题1、标题2；正文字体仿宋_GB2312 三号。
  3. "开始 → 段落"：行距 28 磅，特殊格式首行缩进 2 字符。
  4. 选中图片 → "图片格式 → 环绕 → 上下型"，再"居中"。

题号：2024-W22024年表格与图表

题干：对素材中的"活动参与人数"表格完成以下操作：

  1. 在表格最上方插入一行，写入"项目 人数 比例"作为表头，并设置加粗、底纹。
  2. 使用表格内置公式计算"合计"行的总人数。
  3. 根据该表格数据插入柱形图，标题为"活动参与人数统计"。

📅 2023 年代表性 Word 大题 · 制作"市场调查报告"

题号：2023-W12023年目录与页码

题干：打开"调查报告.docx"，按要求完成：

  1. 将文档分为两节，第一节为封面+目录页（罗马数字页码 I, II…），第二节为正文（阿拉伯数字 1, 2…）。
  2. 封面页不显示页眉页脚。
  3. 插入自动目录，仅显示前两级标题，目录页码使用超链接。
  4. 正文中插入 2 张图片，分别设置"嵌入型"和"紧密型"环绕。
  5. 使用"导航窗格"将文档结构复制为新文档大纲。
参考答案（操作思路）：
  1. "布局 → 分隔符 → 下一页"，分别插入两个分节符。"插入 → 页码 → 设置页码格式"：目录节选"罗马数字"，从 I 开始；正文节选"阿拉伯数字"，从 1 开始。
  2. 封面节单独选中，"页眉页脚工具 → 链接到上一节"取消；勾选"首页不同"。
  3. "引用 → 目录 → 自动目录1"；右键目录 → "更新域 → 更新整个目录"。
  4. "插入 → 图片"，分别设置两种环绕方式。
  5. "视图 → 导航窗格"，右键相应级别"复制大纲"。
核心能力：分节与页码格式、自动目录、图片环绕、导航窗格。
题号：2023-W22023年审阅修订

题干：对"调查报告.docx"进行如下审阅：

  1. 开启修订模式，将正文第一段中"良好"修改为"较好"，将"显著提升"修改为"大幅提升"。
  2. 对第二段添加批注："此处请补充数据来源"。
  3. 使用"比较"功能比较"v1.docx"和"v2.docx"，生成第三版"比较结果.docx"。
  4. 将最终版接受所有修订，并以 PDF 形式导出。
参考答案（操作思路）：
  1. "审阅 → 修订"开启，直接修改文档。
  2. 选中文本 → "审阅 → 新建批注"，输入内容。
  3. "审阅 → 比较 → 比较"，原文档 v1，修订文档 v2，生成新文件。
  4. "审阅 → 接受 → 接受所有修订"；"文件 → 导出 → 创建 PDF/XPS"。
核心能力：修订、批注、比较、PDF 导出。

  3. "编辑收件人列表 → 筛选"，条件"专业=计算机科学"。
  4. "完成并合并 → 编辑单个文档 → 全部"；"另存为"指定文件名。
核心能力：邮件合并、字段插入、筛选。
