学习指南：为什么学、怎么学、学到什么

在动手写代码之前，先建立全局认知 —— C 的本质、C 在计算机体系中的位置，以及一条循序渐进的学习路线。

00.1 为什么学习 C 语言

C 语言是一种通用、过程式、编译型的编程语言，由 Dennis Ritchie 于 1972 年在贝尔实验室为重写 UNIX 操作系统而设计。它具有以下特点：

  • 接近底层：可直接操作内存地址（指针）、位运算，几乎与汇编一一对应；
  • 可移植：同一份源码可在 Windows / Linux / macOS / 嵌入式平台编译运行；
  • 语法相对简洁：核心关键字仅约 30 个；
  • 高性能：生成的机器码效率与汇编相当，被广泛用于性能敏感场景。

C 语言的典型应用领域

  • 操作系统：Linux、macOS、Windows 内核与大量系统组件；
  • 嵌入式系统：单片机、IoT 设备、汽车电子；
  • 编译器与解释器：GCC、Clang、CPython、Redis 等；
  • 驱动程序、数据库（SQLite、Redis）、高性能计算；
  • 网络程序：Nginx、libuv、curl 等基础设施；
  • 教学语言：理解计算机系统底层的最佳载体。

一句话总结：C 是连接高级语言与计算机硬件的"枢纽语言"，学会它能让你真正理解程序如何在机器上运行。

00.2 学习目标 & 路线

完成本课程后，你将能够：

  • 读懂中等复杂度的 C 程序；
  • 独立编写 200 ~ 500 行的小型 C 程序；
  • 熟练使用变量、表达式、控制结构、函数、数组与字符串；
  • 深入理解指针与内存模型（核心难点）；
  • 使用结构体组织数据、动态分配与释放内存；
  • 读写文件、使用预处理与标准库；
  • 使用 gdb / VS Code 调试 C 程序；
  • 独立完成 1 ~ 2 个完整的小项目。

C 诞生于 1970 年代，1989 年由 ANSI 标准化（ANSI C / C89），随后 ISO 跟进（C90）。其后主流标准演进：

C 语言标准演进时间轴

本教程以 C17 / C23 现代 C 视角组织内容，但兼顾 C99 兼容性（编译器默认模式）。

1.3 第一个 C 程序 —— Hello, World!

几乎所有 C 教材的第一个例子，让我们逐行拆解：

hello.c复制
#include <stdio.h>          // 引入标准输入输出头文件

int main(void)                // 主函数：程序入口
{
    printf("Hello, World!\n");  // 输出字符串到屏幕
    return 0;                  // 返回 0 表示正常退出
}

逐行解释

  • #include <stdio.h>：预处理指令，告诉编译器把 stdio.h（标准 I/O 头文件）的内容"粘贴"进来；
  • int main(void)：主函数，每个 C 程序必须有且仅有一个 main，是程序入口；
  • { }：复合语句块，函数体边界；
  • printf(...)：标准库函数，把字符串打印到标准输出；
  • \n：转义字符，代表换行；
  • return 0;：返回 int 类型的退出码，0 表示正常；
  • ;：每条语句以分号结尾（复合语句的 { } 后不需要）。
编译运行：在 Linux/macOS 终端执行 gcc hello.c -o hello && ./hello，在 Windows + MinGW 下同理。

1.4 注释

C 提供两种注释方式：

comments.c复制
// 单行注释：以 // 开头，到行尾结束（C99 引入）

/*
 * 多行注释：以 /* 开头，*/ 结尾
 *  常用于函数说明、临时屏蔽代码块
 */

int main(void) {
    // printf("暂时不执行\n");
    return 0;
}
注意：多行注释 不能嵌套。/* /* */ */ 这种写法会让编译器在第一个 */ 处认为注释结束，导致后面的 */ 报错。

数据类型、变量与运算符

C 是一门强类型语言：每个变量都有明确类型，决定了占用内存大小与可执行的操作。

4.1 基本数据类型与大小

4.2 变量与常量

variable.c复制
#include <stdio.h>

// 宏常量：预处理阶段做文本替换
#define PI       3.1415926
#define MAX_LEN  256

int main(void)
{
    // 变量：值可以改变
    int    age    = 18;
    float  score  = 95.5;
    char   grade  = 'A';

    return 0;
}

4.3 类型转换

  • 自动转换（隐式）：运算时低精度自动提升到高精度（如 int + double → double）；
  • 强制转换：(目标类型)表达式，例如 (int)3.7 得 3（截断小数部分）；
cast.c复制
int    a = 10;
double b = (double)a / 3;     // 3.333...  (true division)
int    c = a / 3;             // 3          (integer division)

// ⚠️ 精度损失：double → int 时小数部分被截断（非四舍五入）
int d = (int)3.99;            // d == 3

程序控制结构：顺序、选择、循环

从"会写语句"到"会写程序"的关键一步——让代码具备判断与重复执行的能力。

5.1 顺序结构：程序的默认执行方式

语句按书写顺序依次执行。最简单的程序：输入 → 处理 → 输出。

seq.c复制
#include <stdio.h>

int main(void) {
    int r;
    printf("请输入半径：");
    scanf("%d", &r);

    double area = 3.1415926 * r * r;
    printf("半径=%d, 面积=%.2f\n", r, area);
    return 0;
}

5.2 选择结构：if / switch

if 三种形式

if.c复制
if (score >= 90)
    printf("A\n");

if (score >= 60)
    printf("及格\n");
else
    printf("不及格\n");

if (score >= 85)
    printf("优秀\n");
else if (score >= 70)
    printf("良好\n");
else if (score >= 60)
    printf("及格\n");
else
    printf("不及格\n");

switch：多分支离散值

switch.c复制
switch (choice) {
case 1:
    printf("新建\n");
    break;
case 2:
    printf("打开\n");
    break;
case 3:
case 4:
    printf("保存 / 另存为\n");
    break;
default:
    printf("无效选项\n");
}
注意：每个 case 通常需要 break 跳出，否则会"贯穿"到下一个 case（少数情况是有意为之）。

5.3 循环结构：while / do-while / for

while：先判断后执行

while.c复制
int i = 0;
while (i < 5) {
    printf("%d\n", i);
    i++;
}

do-while：先执行后判断

dowhile.c复制
int n;
do {
    printf("输入正数：");
    scanf("%d", &n);
} while (n <= 0);

for：经典计数循环

for.c复制
for (int i = 0; i < 10; i++) {
    printf("%d ", i);
}
printf("\n");

循环控制

  • break：立即跳出当前循环或 switch；
  • continue：跳过本次剩余语句，进入下一轮；
  • goto label;：跳转到大一通常不推荐使用，容易破坏结构。

5.4 经典案例：九九乘法表

9x9.c复制
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++)
            printf("%dx%d=%-2d ", j, i, j*i);
        printf("\n");
    }
    return 0;
}

关键：循环嵌套体现"行 × 列"二维结构——外层控制行，内层控制列。

函数与程序模块化

函数是 C 程序的基本构件——把复杂问题拆成可复用、可独立测试的小单元。

6.1 函数定义与调用

func.c复制
#include <stdio.h>

// 函数定义：返回类型 + 名字 + 参数列表 + 函数体
int add(int a, int b) {
    return a + b;
}

// 没有返回值：void
void say_hello(const char* name) {
    printf("Hello, %s!\n", name);
}

int main(void) {
    say_hello("Tom");
    int s = add(3, 4);   // 函数调用
    printf("3+4=%d\n", s);
    return 0;
}

函数声明（原型）

如果函数的定义出现在调用之后，需要先声明（告诉编译器函数签名）：

prototype.c复制
int add(int, int);    // 函数原型（参数名可省略）

int main(void) {
    printf("%d\n", add(1, 2));
    return 0;
}

int add(int a, int b) { return a + b; }

6.2 参数传递：值传递 vs 地址传递

C 的函数参数默认值传递：形参是实参的副本，函数内修改形参不影响实参。

swap.c复制
void swap_wrong(int a, int b) {
    int t = a; a = b; b = t;   // 仅交换副本，原变量不变
}

void swap_ok(int *a, int *b) {
    int t = *a; *a = *b; *b = t;  // 通过地址真正交换
}

记忆：想让函数修改外部变量，必须传地址（指针）。这是后续"指针"章节的核心铺垫。

6.3 作用域与存储类别

变量类型作用域生命周期说明
局部变量所在块 { } 内块结束时销毁函数内定义的变量
全局变量从定义处到文件末程序整个运行期函数外定义，默认初值 0
static 局部所在块内整个程序运行期值在调用之间保留
static 全局当前 .c 文件整个程序运行期不暴露给其他文件
extern整个程序（多文件）整个程序运行期声明在其他文件定义的全局变量

6.4 递归函数：自己调用自己

递归 = 终止条件 + 递归步骤。三个经典例子：

factorial.c复制
long factorial(int n) {
    if (n <= 1) return 1;      // 终止条件
    return n * factorial(n - 1); // 递归步骤
}
// factorial(5) = 5*4*3*2*1 = 120
递归风险：递归太深会栈溢出。Fibonacci 的朴素递归就是反例 —— 应改用迭代或记忆化。

数组与字符串

数组 = 同类型元素的连续存储。字符串 = 以 '\0' 结尾的字符数组。

7.1 一维数组

array1d.c复制
int a[5];                       // 声明：5 个 int，未初始化
int b[5] = {1, 2, 3, 4, 5}; // 全部初始化
int c[5] = {0};                // 全为 0（部分初始化其余补 0）
int d[]  = {10, 20, 30};      // 自动推导长度 = 3

a[0] = 100;                  // 通过下标访问（下标从 0 开始）
printf("%d\n", a[4]);          // 最后一个元素
printf("size=%zu\n", sizeof a); // 20 (5×4)
数组越界：C 不会检查下标越界，访问 a[5]、a[-1] 是未定义行为 —— 后果难以预料。

指针与内存：整个 C 课程的核心难点

指针 = 存储"内存地址"的变量。掌握 * 与 &，你就掌握了 C 的灵魂。

8.1 什么是指针

每个变量都占用一段内存，地址就是这段内存的"门牌号"。指针变量保存的就是这种地址。

ptr.c复制
int  a = 10;       // 整型变量 a，值为 10
int *p = &a;        // p 是指针，指向 a 的地址

printf("a      = %d\n",   a);     // 10
printf("&a     = %p\n",   &a);   // a 的地址
printf("p      = %p\n",   p);     // 同上（p 保存的就是 &a）
printf("*p     = %d\n",   *p);    // 通过 p 间接访问：10

*p = 99;                       // 通过指针修改 a
printf("a 现在是 %d\n", a);     // 99
指针 p 保存了 a 的地址，*p 即"通过地址找值"

8.2 指针运算与数组

数组名 a 在大多数表达式中会退化为指向首元素的指针，因此 a[i] 等价于 *(a+i)。

ptrarr.c复制
int a[5] = {10, 20, 30, 40, 50};
int *p = a;           // 等价于 int *p = &a[0];

printf("%d\n", *(p + 2));   // 30  (p 移动 2 个 int 长度)
printf("%d\n", p[2]);        // 30  (下标写法)

p++;                    // p 现在指向 a[1]
printf("%d\n", *p);         // 20
注意：指针加减的单位是"它指向类型的大小"：int *p; p+1 实际地址加 4 字节（典型 int 大小）。

8.3 动态内存：malloc / free

当数据大小在编译期未知时，使用堆动态分配内存：

malloc.c复制
#include <stdlib.h>

int main(void) {
    int n;
    scanf("%d", &n);

    int *p = malloc(sizeof(int) * n);  // 申请 n 个 int
    if (p == NULL) return 1;           // 必须检查失败

    for (int i = 0; i < n; i++)
        p[i] = i * i;                          // 像普通数组一样用

    free(p);                                  // 用完必须释放
    p = NULL;                             // 避免悬空指针
    return 0;
}
函数作用
malloc(size)申请 size 字节，未初始化，返回 void*
calloc(n, size)申请 n×size 字节并清零
realloc(p, new)调整已分配内存大小
free(p)释放内存（p 必须来自 malloc/calloc/realloc）

8.4 常见内存错误（务必警惕）

错误类型说明防范
野指针未初始化的指针声明时即初始化：int *p = NULL;
悬空指针指向已 free 的内存free 后立即 p = NULL;
NULL 解引用对 NULL 指针使用 *p解引用前检查
内存泄漏malloc 后忘了 free谁申请谁释放；
工具：valgrind / ASan
越界访问数组 / 缓冲区下标越界始终检查下标范围
重复释放对同一指针 free 两次free 后置 NULL
调试利器：Linux 下 valgrind --leak-check=full ./a.out；GCC/Clang 编译加 -fsanitize=address 可捕获大多数内存错误。

8.5 函数指针 & 多级指针（拓展）

funcptr.c复制
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main(void) {
    int (*fp)(int, int) = add;   // 函数指针
    printf("%d\n", fp(3, 2));   // 5  (像函数一样调用)
    fp = sub;
    printf("%d\n", fp(3, 2));   // 1
}

int **pp;   // 二级指针：指向"指向 int 的指针"

结构体、枚举与自定义类型

9.1 结构体（struct）

算法基础：查找、排序与递归

掌握 5 ~ 8 个基础算法，足以应对大一编程作业与面试入门。

12.1 顺序查找 & 二分查找

顺序查找 O(n)

linear.c复制
int linear_search(int a[], int n, int key) {
    for (int i = 0; i < n; i++)
        if (a[i] == key) return i;
    return -1;
}

二分查找 O(log n)（要求数组有序）

binary.c复制
int binary_search(int a[], int n, int key) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (a[mid] == key)   return mid;
        else if (a[mid] < key) lo = mid + 1;
        else                 hi = mid - 1;
    }
    return -1;
}

12.2 基础排序：冒泡 / 选择 / 插入

bubble.c复制
// 冒泡排序：相邻元素两两比较交换，每轮把最大元素"冒"到末尾
void bubble_sort(int a[], int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
            }
}

12.3 经典递归：阶乘 / Fibonacci / 汉诺塔

fib.c复制
// 朴素递归 Fibonacci（教学示例，效率极低）
int fib(int n) {
    if (n < 2) return n;
    return fib(n - 1) + fib(n - 2);
}

// 迭代版：O(n) 时间 O(1) 空间（推荐）
long fib_iter(int n) {
    if (n < 2) return n;
    long a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        long c = a + b;
        a = b; b = c;
    }
    return b;
}

13.3 编程规范建议

  • 命名：变量小写、函数驼峰或下划线、常量全大写；避免单字母（除循环计数 i/j/k）；
  • 缩进：统一 4 空格或 1 Tab；
  • 注释：解释"为什么"而不是"是什么"；公开 API 必须有注释；
  • 函数长度：尽量不超过一屏（≈ 50 行）；
  • 模块化：一个函数做一件事；高内聚低耦合；
  • 错误处理：每个系统调用、malloc、文件操作都检查返回值；
  • 避免魔数：用 #define 或 const 给数值起名。

项目一：猜数字游戏 🎲

难度 ★☆☆ · 涉及：循环 / 条件 / 随机数 / 函数

程序随机生成 1 ~ 100 的整数，玩家循环输入猜测，程序给出"大了 / 小了"提示，直到猜中。

guess.c复制
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand((unsigned)time(NULL));
    int target = rand() % 100 + 1;
    int guess, tries = 0;

    do {
        printf("猜一个 1-100 的数：");
        scanf("%d", &guess);
        tries++;
        if (guess > target)      printf("大了！\n");
        else if (guess < target) printf("小了！\n");
    } while (guess != target);

    printf("恭喜！用了 %d 次猜中。\n", tries);
    return 0;
}
