学习指南：为什么学、怎么学、学到什么

在动手写代码之前，先建立全局认知 —— Java 的本质、JVM 的运行原理，以及一条循序渐进的学习路线。

00.1 什么是 Java

Java 由 Sun Microsystems 公司于 1995 年发布，2010 年后由 Oracle 维护。它是一门面向对象、跨平台、强类型的通用编程语言。

Java 的核心特点

  • 面向对象：一切皆对象，OOP 是 Java 的灵魂；
  • 跨平台：一次编译，到处运行（Write Once, Run Anywhere）；
  • 自动内存管理：GC 机制自动回收不再使用的内存；
  • 强类型：编译期检查大量类型错误；
  • 丰富的标准类库：JDK 自带数千个类，从集合到网络、并发；
  • 异常处理机制：把错误处理与正常逻辑分离。

Java 的应用领域

  • 企业级后端：Spring / Spring Boot 占据 Web 后端主流；
  • Android 应用（Java / Kotlin 历史主流）；
  • 大数据生态：Hadoop / Kafka / Flink / Elasticsearch；
  • 服务端中间件：Tomcat / Netty / Dubbo；
  • 金融/电信系统、嵌入式；
  • 科学计算 / 教学：MIT、Stanford 等知名课程使用 Java。
Java 与 C/C++ 的关系：Java 借鉴了 C/C++ 的语法，但移除了指针、多继承等复杂特性，加入了垃圾回收和虚拟机，是更"安全友好"的选择。

一句话总结：Java 是工业界应用最广的 OOP 语言之一 —— 学好它，能打开从后端到大数据的整片职业空间。

00.2 Java 程序运行原理：JVM 是关键

Java 程序不是直接编译成机器码，而是先编译成 字节码（.class），再由 JVM 翻译成机器码执行。这就是"一次编译，到处运行"的秘密。

Java 程序运行流程：源代码 → 字节码 → JVM → 机器码

JDK / JRE / JVM 三者关系

    • void：无返回值；
    • String[] args：命令行参数；
  • System.out.println(...)：把字符串打印到标准输出，并换行。

3.2 引用类型 vs 基本类型

基本类型（8 种）

  • 存的是实际数值，在栈上分配；
  • 传递时是值拷贝；
  • 不能为 null（除非用包装类）；
  • 大小固定，与机器无关。

引用类型

  • 如 String、数组、对象；
  • 存的是堆上对象的地址；
  • 可为 null；
  • Java 的"一切皆对象"指的就是这些。
Java基本 vs 引用
int     a = 10;                  // 基本类型，存 10
String s = "Hello";            // 引用类型，存的是字符串对象的地址

int     b = a;                  // 值拷贝：b 也等于 10
String t = s;                  // 地址拷贝：t 与 s 指向同一对象

4.4 综合练习：猜数字小游戏

import java.util.Scanner;
import java.util.Random;

public class GuessNumber {
    public static void main(String[] args) {
        Random r = new Random();
        int target = r.nextInt(100) + 1;     // 1~100
        Scanner sc = new Scanner(System.in);
        int guess, tries = 0;

        do {
            System.out.print("猜一个 1-100 的数：");
            guess = sc.nextInt();
            tries++;
            if (guess > target)      System.out.println("大了！");
            else if (guess < target) System.out.println("小了！");
        } while (guess != target);

        System.out.printf("用了 %d 次猜中！\n", tries);
    }
}

方法与程序结构

方法 = C/C++ 中的"函数"。Java 中所有方法都必须属于类。

6.1 方法定义、参数与返回值

JavaMethodDemo.java
public class MethodDemo {
    // 无返回值
    public static void sayHi(String name) {
        System.out.println("Hi, " + name);
    }

    // 有返回值
    public static int add(int a, int b) {
        return a + b;
    }

    // 方法重载：同名不同参
    public static double add(double a, double b) {
        return a + b;
    }

    // 可变参数（必须是最后一个参数）
    public static int sum(int... nums) {
        int total = 0;
        for (int n : nums) total += n;
        return total;
    }

    public static void main(String[] args) {
        sayHi("Alice");
        System.out.println(add(3, 5));         // 8
        System.out.println(sum(1, 2, 3, 4, 5)); // 15
    }
}

6.2 值传递 vs 引用传递 ⭐

Java 只有值传递。对于引用类型，传的是"地址值的拷贝"——修改对象内容会影响原对象，但改变形参指向不影响原引用。

JavaPassDemo.java
// 1) 基本类型：完全拷贝，互不影响
static void swapInt(int a, int b) {
    int t = a; a = b; b = t;   // 仅在方法内交换
}

// 2) 引用类型：可以修改对象内容，但不能改变原引用指向
static void modify(int[] arr) {
    arr[0] = 999;            // ✔ 修改原数组元素
}

6.3 递归：阶乘与 Fibonacci

JavaRecursion.java
static long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

// Fibonacci：朴素递归效率极低，实际应用应改用迭代
static long fib(int n) {
    if (n < 2) return n;
    return fib(n - 1) + fib(n - 2);
}

// 迭代版 Fibonacci：O(n) 时间，O(1) 空间
static long fibIter(int n) {
    if (n < 2) return n;
    long a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        long c = a + b; a = b; b = c;
    }
    return b;
}

面向对象编程 ⭐⭐⭐ —— Java 的灵魂

本章是整个 Java 课程的核心。请把更多时间放在这里——把每一节都动手写一遍。

7.1 面向对象思想：从"操作"到"建模"

面向过程（C 风格）

把程序看作一系列函数调用，数据与行为分离。

C面向过程
// 单独的数据 + 单独的函数
struct Student { char name[32]; int age; };

void setAge(struct Student* s, int a) {
    s->age = a;
}

面向对象（Java 风格）

把数据和行为封装进同一个"类"，对象之间通过消息协作。

Java面向对象
// 数据 + 行为打包在一起
class Student {
    private String name;
    private int age;
    public void setAge(int a) { this.age = a; }
    public int  getAge()      { return age; }
}

OOP 三大特性：封装（数据隐藏 + 行为内聚） · 继承（代码复用 + 类型扩展） · 多态（同一消息，不同响应）。这三大特性是 OOP 思想的精髓，Java 在语法层面对它们的支持堪称典范。

7.2 定义类与创建对象 ⭐

类 = 对象的模板。Java 中所有代码都必须写在类里（除了少数注释和包声明）。

JavaStudent.java
public class Student {
    // 成员变量（字段）—— 推荐 private
    private String name;
    private int    age;
    private double score;

    // 构造方法（Constructor）：用于初始化对象
    public Student() {
        this("Unknown", 0, 0.0);              // 调用其他构造
    }

    public Student(String name, int age) {
        this(name, age, 0.0);
    }

    public Student(String name, int age, double score) {
        this.name  = name;
        this.age   = age;
        this.score = score;
    }

    // 公开方法
    public void study() {
        System.out.println(name + " 在学习");
    }

    public void printInfo() {
        System.out.printf("%s, %d 岁, %.1f 分%n", name, age, score);
    }
}
Java使用 Student
public class Main {
    public static void main(String[] args) {
        // 创建对象：new 调用构造方法
        Student s1 = new Student();                          // 调用无参构造
        Student s2 = new Student("Alice", 20, 95.5);    // 调用带参构造

        s2.study();
        s2.printInfo();
    }
}
this 关键字：指向"当前对象"。可用于区分成员变量与形参同名（this.name = name），也可用于在一个构造方法中调用另一个（this(...)）。

7.3 封装：访问控制 + Getter/Setter ⭐

封装的核心：把数据藏起来，把方法暴露出去。外部只能通过公开方法访问数据，从而保证数据有效性。

修饰符本类同包子类其他类

protected✔✔✔✘

JavaAccount.java — 封装示例
public class Account {
    private String owner;
    private double balance;       // 余额：必须保持非负

    public Account(String owner, double init) {
        this.owner   = owner;
        this.balance = init >= 0 ? init : 0;
    }

    // 通过 getter 读，通过 setter 受控地写
    public String getOwner()   { return owner; }
    public double getBalance() { return balance; }

    // 业务方法：体现"行为"
    public void deposit(double amount) {
        if (amount <= 0) throw new IllegalArgumentException("金额必须为正");
        balance += amount;
    }

    public void withdraw(double amount) {
        if (amount > balance) throw new IllegalArgumentException("余额不足");
        balance -= amount;
    }
}
经验法则：所有成员变量都用 private；必要时提供 public getter/setter；数据校验放在 setter 或业务方法中。

7.4 static 与 final：类级别的成员

7.5 继承：extends ⭐

Java 只支持单继承（一个类只能 extends 一个父类）。多继承通过接口实现。

JavaInheritanceDemo.java
// 父类
public class Person {
    protected String name;
    protected int    age;

    public Person(String name, int age) {
        this.name = name; this.age = age;
    }

    public void sayHi() {
        System.out.println("Hi, 我叫 " + name);
    }
}

// 子类
public class Student extends Person {
    private String school;

    public Student(String name, int age, String school) {
        super(name, age);              // 调用父类构造（必须第一句）
        this.school = school;
    }

    @Override                    // 方法重写（覆盖父类）
    public void sayHi() {
        super.sayHi();               // 调用父类版本
        System.out.println("我在 " + school + " 上学");
    }
}
super 关键字：在子类中访问父类的成员（构造、方法、字段）。

7.6 方法重写（Override）与 @Override

子类可以重写父类的方法，提供自己的实现。@Override 注解让编译器帮你检查是否真的覆盖了父类方法。

JavaOverride.java
class Animal {
    public void sound() {
        System.out.println("...");
    }
}

class Dog extends Animal {
    @Override                     // 强烈推荐：编译器会校验
    public void sound() {
        System.out.println("汪汪！");
    }
}

class Cat extends Animal {
    @Override
    public void sound() {
        System.out.println("喵喵！");
    }
}
重写规则：方法名、参数列表必须相同；返回类型可以是父类方法返回类型的子类（协变）；访问权限不能更严格；不能重写 static、private、final 方法。

7.7 多态：同一接口，不同实现 ⭐⭐⭐

多态是 OOP 的精髓：父类引用指向子类对象，调用方法时执行子类版本。

JavaPolymorphismDemo.java
public class PolymorphismDemo {
    public static void main(String[] args) {
        // 父类引用 → 子类对象
        Animal a1 = new Dog();
        Animal a2 = new Cat();

        makeSound(a1);   // 汪汪！
        makeSound(a2);   // 喵喵！

        // 多态数组：处理一组"形状"
        Animal[] animals = {new Dog(), new Cat(), new Animal()};
        for (Animal a : animals) a.sound();
    }

    // 接受父类引用：实际执行子类的方法
    static void makeSound(Animal a) {
        a.sound();
    }
}
多态三要素：① 继承 ② 方法重写 ③ 父类引用指向子类对象。这三者缺一不可。

7.8 抽象类：abstract ⭐

包含抽象方法（没有实现的方法）的类必须用 abstract 修饰，不能直接实例化。

JavaAbstractShape.java
public abstract class Shape {
    protected String color;

    public Shape(String color) { this.color = color; }

    // 抽象方法：只有签名，没有实现
    public abstract double area();
    public abstract double perimeter();

    // 普通方法可以保留
    public String getColor() { return color; }
}

public class Circle extends Shape {
    private double r;
    public Circle(String color, double r) {
        super(color); this.r = r;
    }
    @Override public double area()      { return 3.14159 * r * r; }
    @Override public double perimeter() { return 2 * 3.14159 * r; }
}

// Shape s = new Shape();   // ❌ 不能实例化抽象类
Shape s = new Circle("Red", 2.0);    // ✔ 多态

7.9 接口：interface ⭐⭐

接口定义"做什么"，类实现"怎么做"。一个类可以实现多个接口（弥补 Java 单继承）。

JavaInterfaceDemo.java
// 接口：只声明"做什么"，不写"怎么做"
public interface Flyable {
    void fly();                  // 默认 public abstract

    // Java 8+ 默认方法（有实现）
    default void land() {
        System.out.println("着陆");
    }

    // Java 8+ 静态方法
    static boolean canFly(Flyable f) {
        return f != null;
    }
}

public interface Swimmable {
    void swim();
}

// 类实现多个接口（弥补 Java 单继承）
public class Duck extends Animal implements Flyable, Swimmable {
    @Override public void fly()  { System.out.println("鸭子飞"); }
    @Override public void swim() { System.out.println("鸭子游"); }
}
抽象类 vs 接口：抽象类是"is-a"（是什么），共享代码；接口是"can-do"（能做什么），定义能力。Java 中优先用接口。

7.10 Object 类：所有类的祖宗

Java 专属常见 bug

  • NullPointerException：对象未初始化就被访问；
  • ArrayIndexOutOfBoundsException：下标越界；
  • ClassCastException：类型转换错误；
  • 字符串比较用 ==：必须用 equals；
  • 资源未关闭：用 try-with-resources；
  • ConcurrentModificationException：遍历时修改集合；
  • 死锁：多线程加锁顺序不一致。

数据结构与算法（Java 实现）

Java 自带集合框架覆盖了大部分常用结构；自定义时建议继承或参考现有接口。

单链表实现

JavaLinkedListDemo.java
class Node<T> {
    T data;
    Node<T> next;
    Node(T d) { data = d; }
}

public class MyLinkedList<T> {
    private Node<T> head;

    public void addFirst(T v) {
        Node<T> n = new Node<>(v);
        n.next = head;
        head = n;
    }

    public void print() {
        for (Node<T> p = head; p != null; p = p.next)
            System.out.print(p.data + " -> ");
        System.out.println("null");
    }
}
